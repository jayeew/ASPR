Reviewer #1 
(Remarks to the Author) 
Wu and colleagues present GPTL, an R package to fit polygenic scores using multi-ancestry data. This package implements
three methods (two being new) based on transfer learning to use PGS effect sizes learned from a large European dataset to
guide the learning of PGS effect sizes in an underrepresented population. While this is an important problem, I don't think the
proposed methodologies improve upon the existing methods already available, so I cannot recommend this for publication in
Nature Communications. 
- The package uses sufficient statistics including X'X as a dense R matrix, which is extremely inefficient. The authors
mention being able to use tens of thousands of variants, which is far from being “scalable”. Most PGS methods currently use
more than 1M variants; being scalable would mean using 7-10M. I guess this is why the authors restrict to variants with a p-
value lower than 1e-5 in their analyses, which is known to be suboptimal in many settings. 
- Using a penalty on the difference of effect sizes seems similar to what PROSPER does. 
- The TL methods are not really providing better performance than simply combining effects from single-ancestry PGS.
Moreover, I would imagine that one could get even better performance if using more optimal PGS methods for both single-
ancestry and multi-ancestry, which the authors do not compare to. 
- Results could be more descriptive (with actual numbers). 
Signed Florian Privé

Reviewer #2 
(Remarks to the Author) 
The reliance on both in-sample and out-of-sample linkage disequilibrium (LD) presents a significant limitation. If the package
only functions when in-sample LD data are available, its applicability becomes quite restricted. Although the authors claim
that their method can be applied to summary GWAS statistics, it appears that individual-level data are still required to
compute the LD matrix. Additionally, while lines 559–566 mention that the method can utilize external LD reference panels,
there is no simulation or real-data analysis provided to substantiate this claim. The statement that the method is "slightly
worse" than existing approaches lacks quantification—how much worse is it? If the performance degradation is substantial,
the practical utility of the method could be compromised. Notably, other multi-ancestry methods successfully leverage
reference panels such as the 1000 Genomes Project or UK Biobank, which are more flexible in this regard. 
Another concern pertains to the comparison with existing polygenic score (PGS) methods. The authors suggest that their
method could achieve better performance with more optimal PGS approaches for both single- and multi-ancestry analyses.
However, they do not include such comparisons. To strengthen their claims, it would be valuable to evaluate their method
against established single-ancestry approaches like lassosum, LDpred, or other classical methods. Demonstrating that their
transfer learning approach offers a tangible advantage over these methods would significantly bolster the paper’s
contribution. Incorporating additional simulations or real-data analyses to support these points would be worthwhile,
although it would involve considerable effort.

Dear Reviewers,
We are very thankful for the comments and suggestions received. In response, we have made 
multiple revisions, which resulted in a much-improved manuscript and software. Major revisions 
include:
Implementing TL with sparse LD reference panels and GWAS summary statistics. The new 
version of the GPTL R-package that we introduce with the manuscript can be used with sufficient 
statistics (dense or sparse) derived from individual-level genotype and phenotype data or with 
GWAS summary statistics and sparse LD reference panels. With these enhancements, our software 
can be used to fit PGS with millions of variants. We present real data benchmarks using nearly 1 
million variants in the revised manuscript. 
Presenting new benchmarks of the TL methods using all the available variants  (i.e., without 
p-value thresholding). In these benchmarks, we compare the three TL algorithms with PRS-CSx 
and PROSPER. These analyses show that: (i) the PGS we previously presented (using p-value 
thresholding and dense LD matrices) achieved higher prediction accuracy than those using all the 
available markers (including PRS-CSx and PROSPER) by a sizable margin; and (ii) the TL 
algorithms included in the GPTL R-package are considerably faster and performing slightly better 
in terms of accuracy than the best PRS-CSx or PROSPER ensembles. As a by-product of the work 
done in the revisions, we provide with the manuscript LD reference panels for Hispanics and 
African Americans derived using All of Us (AOU) data for nearly 1 million variants present in 
AOU, along with GWAS results for each of these ancestry groups and 11 traits. These panels and 
GWAS results will facilitate PGS investigations using this new and valuable data set.
Assessing the sensitivity of PGS derived using p-value thresholding with respect to the 
threshold used. This addresses a request from one of the reviewers and sheds light on the impact 
of adding to PGS large numbers of small-effect variants that previous studies suggest have poor 
portability between ancestry groups.
Evaluating the impact of using sparse LD matrices on PGS prediction accuracy for non-EUs. 
We used sparse block-diagonal matrices along chromosomes (i.e., only ignoring LD between 
chromosomes) and along LD-blocks (i.e., ignoring LD between blocks). The use of sparse LD 
matrices significantly improved computational speed. We also show that ignoring LD between 
blocks can reduce prediction accuracy, particularly in Hispanics, an admixed population where LD 
does not decrease as quickly and smoothly as in EUs. 
In what follows, we provide our point-by-point response to reviewer comments with all modified 
text presented in red font. 
We hope you find the revised manuscript suitable for publication in Nature Communications.
