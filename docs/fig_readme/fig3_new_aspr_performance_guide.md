## 1. 技术摘要：这项实验最终证明了什么

Fig. 3 检验的是一个严格的**时间外预测问题**：仅使用论文发表时已经能够获得的
T0 指标，能否对论文发表后 3 年、5 年和 8 年的科学吸收与跨领域扩散进行可靠排序。

最终结果支持以下四点：

1. **ASPR具有明显的时间外排序能力。**正式模型 D5 × Full-text 16 的总体 OOF
   Spearman 为 `ρ = 0.7371`。这表示在从未参与相应模型训练的后续年份论文中，
   ASPR预测排序与五年期实际科学扩散排序保持较强一致性。
2. **高分论文显著富集未来高扩散论文。**在每个外层时间测试折内部划分十分位后，
   正式模型最高预测十分位 D10 中有 `42.08%` 的论文进入同一测试折的实际五年扩散
   前10%，相对于约10%的参考比例为 `4.21×` 富集；最低预测十分位仅为 `1.09%`。
3. **性能并非只来自某个年份或某个领域。**三年后向窗口地形覆盖12个领域和连续年份；
   在当前扩充版数据中，全部成熟单元都达到 `n ≥ 30`，不存在因样本不足产生的白格。
   同时，领域和年代之间仍存在真实异质性，说明ASPR是稳定但并非均匀的预测信号。
4. **16项高证据指标已经捕获主要增量信息。**D5局部窗口中，Full-text 16 相对
   Strict 7 的中位增益为 `+0.0102`，`76.0%` 的可靠单元为正；继续扩展到154项或
   221项时，中位增益分别只有 `+0.0040` 和 `+0.0005`，表现出明显的预测饱和。

这些结果支持把ASPR用于论文发表时的**前瞻性筛查、排序和观察**，但不支持以下推断：

- ASPR分数是论文“创新性真值”；
- 高ASPR导致了后续影响；
- 低ASPR论文没有科学价值；
- 不同领域或时代的制度差异已经被完全消除。

整张图最重要的解释边界是：

> **ASPR是预测信号，不是因果估计，也不是直接的新颖性裁决。**

## 2. Fig. 1、Fig. 2 与 Fig. 3 的逻辑分工

三张图构成一条从理论观察到可验证预测的递进链：

```text
Fig. 1：论文发表时能够观察到哪些多维结构信号？
    ↓
Fig. 2：这些指标来自什么证据，如何被冻结为7/16/154/221四套集合？
    ↓
Fig. 3：冻结后的指标能否在严格时间外测试中预示后续科学扩散？
```

因此，Fig. 3 不再重新定义指标、重新选择维度或根据性能修改集合成员。四套集合的
成员资格来自Fig. 2的结果盲证据规则，Fig. 3只承担**预测验证与性能结构解释**。

这种分工十分重要：如果根据Fig. 3的OOF表现反向删改Fig. 2的指标，就会把验证数据
重新带回特征选择过程，破坏“结果盲冻结集合”的方法学优势。

| 问题 | 对应面板 | 需要的证据 |

分数如何产生

## 4. 数据范围、分析队列与时间成熟边界

### 4.1 当前统一数据版本

本图只使用当前激活的 `nature-multihorizon-uncapped-v2` 数据和完整重训结果，
不读取旧Fig. 3，也不使用模拟值。正式12领域论文宇宙包含 `411,490` 篇来自
Nature、Nature Communications和Scientific Reports的论文，论文元数据更新至2022年，
并统一生成T0特征。

四套指标矩阵覆盖同一批411,490篇论文：

| 特征集合 | 指标数 | Fig. 2中的角色 | 在Fig. 3中的用途 |
|---|---:|---|---|
| Strict 7 | 7 | 通过全部严格证据与可复现门槛的确认性核心 | 最严格基线 |
| Full-text 16 | 16 | 包含Strict 7，并加入有英文全文/公式证据的9项指标 | 正式高证据模型集合 |
| Primary 154 | 154 | 来源驱动、T0安全且可规模化的主集合 | 检查大规模扩展是否继续增益 |
| Broad T0 221 | 221 | 更宽松的T0安全上界 | 敏感性与预测饱和边界 |

四套集合是严格嵌套关系：

```text
Strict 7 ⊂ Full-text 16 ⊂ Primary 154 ⊂ Broad T0 221
```

这里的154和221不表示全部指标都是原始公式的逐字复刻。按照Fig. 2的证据分层，
它们包含直接公式、本地透明替代、结构化构念代理和词汇/分类代理。因而，更多指标
意味着更宽的可操作化覆盖，而不意味着单个指标证据更强。

### 4.2 三个结果窗口

对发表年为 `t` 的论文：

- D3观察 `t+1` 至 `t+3`；
- D5观察 `t+1` 至 `t+5`；
- D8观察 `t+1` 至 `t+8`。

因为未来结果需要等待，不同窗口的成熟论文截止年不同：

| 窗口 | 标签成熟截止发表年 | 原始OOF行/特征集 | 有限预测—标签对/特征集 | 因结果缺失排除 |
|---|---:|---:|---:|---:|
| D3 | 2022 | 396,300 | 395,138 | 1,162 |
| D5 | 2020 | 317,995 | 317,262 | 733 |
| D8 | 2017 | 220,633 | 220,293 | 340 |

“原始OOF行”包括已产生预测、但合并扩散标签因未来施引者分类信息不完整而无法定义的
论文。Panel b和Panel c只使用有限预测—标签对；这些缺失不会被错误地当作零影响。

### 4.3 为什么D5是正式窗口

D5在实验协议中预先定义为正式目标，而D3和D8承担补充稳健性验证：

- D3反馈更快、成熟论文更多，但较短时间可能尚未充分显现扩散；
- D8信号更成熟，当前总体相关也更高，但需要等待更久，能覆盖的近期论文更少；
- D5在结果成熟度、部署等待时间和可用样本之间形成主要折中。

因此，D8 × Full-text 16 的总体OOF Spearman虽然达到全图最高的 `0.7723`，
也不能据此替代正式D5模型。它回答的是八年结果，而不是同一个五年部署任务。

## 5. 监督标签究竟是什么

监督标签不是人工标注的“创新/不创新”，也不是简单的未来引用次数。它分两阶段构造。

### 5.1 第一阶段：未来是否发生科学吸收

```text
future_uptake = 1[n_future_citers > 0]
```

- 未来窗口内至少有一个施引者：`future_uptake = 1`；
- 未来请求成功且明确没有施引者：`future_uptake = 0`；
- 未来数据请求失败或状态未知：保持缺失，不能改写为0。

### 5.2 第二阶段：已被吸收后扩散得有多广

仅在 `future_uptake = 1` 且未来施引者taxonomy信息合格时，构造条件扩散标签。
其底层分量包括：

1. 未来施引者覆盖的不同primary field数量；
2. 不同subfield数量；
3. 不同topic数量；
4. field分布的Simpson均衡度；
5. topic分布的Simpson均衡度。

每个外层训练折独立建立参考分布，把三个reach分量的 `log1p` 值和两个Simpson分量
转换为训练折经验分位：

```text
Breadth = mean(
  percentile_train[log1p(field reach)],
  percentile_train[log1p(subfield reach)],
  percentile_train[log1p(topic reach)]
)

Evenness = mean(
  percentile_train[field Simpson],
  percentile_train[topic Simpson]
)

conditional diffusion = 0.5 × Breadth + 0.5 × Evenness
```

### 5.3 最终用于排名评估的实际结果

```text
realized_diffusion_target =
    0                       if future_uptake = 0
    conditional diffusion   if uptake = 1 and taxonomy is valid
    missing                 if uptake = 1 but taxonomy is invalid
```

所以Fig. 3中的Spearman真正回答的是：

> 模型能否把未参与训练的后续论文，按照其未来是否被吸收以及被吸收后传播到多广的
> 综合结果进行正确排序？

它不等于“预测未来会获得多少次引用”。

## 6. 模型、校准和时间外OOF设计

### 6.1 两部分HGB模型

四套特征集合都使用同一固定HGB协议：

1. `HistGradientBoostingClassifier`预测未来吸收概率；
2. `HistGradientBoostingRegressor`只在正uptake训练论文中预测条件扩散程度。

两个部分经过训练折内校准后相乘：

```text
raw_prediction_score
= calibrated P(future uptake = 1 | T0 indicators)
  × calibrated E(diffusion | uptake = 1, T0 indicators)
```

这使得原始预测同时考虑“是否会被后续科学工作吸收”和“若被吸收，扩散范围有多广”。
uptake概率使用内层时间OOF预测进行Platt logistic校准；条件扩散使用限制在 `[0,1]`
范围内的isotonic校准。校准器同样不能读取当前外层测试折的结果。

固定HGB参数为：

| 参数 | 值 |
|---|---:|
| `max_leaf_nodes` | 31 |
| `max_depth` | 4 |
| `min_samples_leaf` | 50 |
| `learning_rate` | 0.05 |
| `max_iter` | 200 |
| `l2_regularization` | 10.0 |
| 内层时间折 | 4 |
| 随机种子 | 20260806 |

参数没有根据外层OOF结果逐图调整。预处理、缺失处理、目标坐标和校准也只能在当前训练折
内部拟合。

### 6.2 为什么不能使用随机K-fold

随机K-fold会让较晚发表的论文帮助预测较早论文，无法代表真实部署。Fig. 3使用
expanding-year forward OOF：每折的训练年份严格早于测试年份。

| 外折 | 训练论文年份 | 测试论文年份 | D3 | D5 | D8 |
|---|---|---|:---:|:---:|:---:|
| 1 | ≤1985 | 1986–1999 | ✓ | ✓ | ✓ |
| 2 | ≤1999 | 2000–2004 | ✓ | ✓ | ✓ |
| 3 | ≤2004 | 2005–2009 | ✓ | ✓ | ✓ |
| 4 | ≤2009 | 2010–2012 | ✓ | ✓ | ✓ |
| 5 | ≤2012 | 2013 | ✓ | ✓ | ✓ |
| 6 | ≤2013 | 2014–2017 | ✓ | ✓ | ✓ |
| 7 | ≤2017 | 2018–2020 | ✓ | ✓ | — |
| 8 | ≤2020 | 2021–2022 | ✓ | — | — |

所有外层预测拼接后才计算总体OOF指标。因此，“OOF”意味着每篇论文的预测都来自一个
没有见过该论文、且只见过更早年份的模型。

### 6.3 四套集合的总体OOF表现

| 窗口 | Strict 7 | Full-text 16 | Primary 154 | Broad T0 221 |
|---|---:|---:|---:|---:|
| D3 | 0.6972 | **0.7160** | 0.6992 | 0.7011 |
| D5 | 0.7205 | **0.7371** | 0.7293 | 0.7313 |
| D8 | 0.7575 | **0.7723** | 0.7707 | 0.7709 |

Full-text 16在三个窗口都取得该窗口最高总体OOF Spearman。正式模型选择为
`D5 × Full-text 16 × HGB`，依据是：D5为预先定义的正式预测窗口，而Full-text 16
在D5四套冻结集合中表现最高。图中的琥珀色边框表示**正式身份**，不是“在所有窗口中
数值绝对最高”或“统计显著性框”。

## 7. Panel a：ASPR分数如何产生

### 7.1 五个流程节点

Panel a从左到右包含五个等宽节点：

```text
T0 indicators
→ two-part HGB
→ raw score
→ D5 ECDF
→ ASPR 0–100
```

逐节点含义如下：

1. **T0 indicators**：只输入发表时或严格发表前可获得的Full-text 16指标；
2. **two-part HGB**：分别建模未来uptake与条件扩散；
3. **raw score**：得到两部分相乘后的五年期预期科学扩散；
4. **D5 ECDF**：使用成熟D5训练参考群体的经验累积分布函数进行百分位映射；
5. **ASPR 0–100**：输出适合排序和交流的正式ASPR分数。

最后一个节点使用更深的蓝色边框和填充，是为了强调最终交付变量，不表示一个新模型。
节点之间的小箭头只表示计算顺序，不表示因果关系。

### 7.2 公式框

浅灰蓝公式框写出两个核心定义：

```text
raw = P(uptake) × E(diffusion | uptake)
ASPR = 100 × ECDF_D5(raw)
```

两个字段应这样理解：

| 字段 | 含义 | 适合用途 | 不应怎样解释 |
|---|---|---|---|
| `raw_prediction_score` | 模型尺度上的五年预期扩散值 | 模型诊断、重新校准、方法比较 | 不是未来引用次数 |
| `aspr_score` | raw值在成熟D5参考群体中的0–100相对百分位 | 排序、筛查、面向读者报告 | 不是“绝对创新程度百分比” |

当前为 `411,490` 篇论文生成正式分数。原始预测范围约为 `0.0051–0.9849`；
实际ASPR百分位范围约为 `0.0018–100`，并且对raw严格保持单调。因此，百分位转换
不会改变论文排序，只改变表达尺度。

例如，`ASPR = 90`应读作：该论文的模型原始预测大约高于成熟D5参考群体中90%的论文。
它不表示该论文有90%的概率成为创新论文，也不表示有90%的概率进入实际扩散前10%。

### 7.3 面板底部两条声明

- `411,490 papers · mature D5 ≤ 2020`：分数覆盖论文更新至2022年，但用于D5经验
  分位参考的成熟论文截止到2020年；
- `Predictive signal—not causality or novelty`：这是整张图的主张边界，而不是普通脚注。

## 8. Panel b：12张十分位曲线如何证明“高分有用”

### 8.1 3 × 4布局

Panel b的行表示预测窗口，列表示冻结特征集合：

|  | Strict 7 | Full-text 16 | Primary 154 | Broad T0 221 |
|---|---|---|---|---|
| 第一行 | D3 | D3 | D3 | D3 |
| 第二行 | D5 | **D5正式模型** | D5 | D5 |
| 第三行 | D8 | D8 | D8 | D8 |

列颜色只帮助区分特征集合：Strict 7为深蓝、Full-text 16为浅蓝、Primary 154为橙色、
Broad T0 221为红色。颜色不直接编码性能高低，不能因为红色更暖就认为221一定更好。

### 8.2 每张小图怎样计算

在每个 `horizon × feature set × outer fold` 内部分别进行：

1. 按OOF预测值把论文分为近似等量的D1–D10；
2. 按同一测试折的实际扩散标签定义实际前10%；
3. 计算每个预测十分位中进入实际前10%的论文比例；
4. 再把各时间折的OOF记录汇总为曲线。

预测十分位和实际前10%都在折内定义，避免早期与后期论文的结果分布变化直接造成
表面富集。

### 8.3 图中每个元素的含义

| 视觉元素 | 含义 |
|---|---|
| 横轴D1–D10 | 由低到高的OOF预测十分位；D10是最高预测组 |
| 纵轴百分比 | 该预测组中进入实际扩散前10%的论文比例 |
| 彩色连线 | 十个十分位之间的排序梯度；连线仅辅助观察，不假设连续函数 |
| D1–D9白心圆 | 普通十分位观测值 |
| D10实心大圆 | 最高预测十分位，承担主要筛查解释 |
| 灰色竖向误差线 | 2,000次出版年份区块bootstrap的95%区间 |
| 约10%灰色虚线 | 若预测组与真实前10%无关时的参考比例 |
| D10旁两行数字 | 第一行为D10命中率，第二行为相对基线的富集倍数 |
| 琥珀色边框与星号 | D5 × Full-text 16正式ASPR模型身份 |

年份区块bootstrap把整年作为重抽样单位，目的是让置信区间反映年度组成和时代变化，
而不是把所有论文错误地视为完全独立同分布。区间描述曲线对出版年份构成的敏感性，
不等同于模型参数置信区间。

### 8.4 D10的全部精确结果

| 窗口 | Strict 7 | Full-text 16 | Primary 154 | Broad T0 221 |
|---|---:|---:|---:|---:|
| D3 | 39.94% / 3.99× | 42.36% / 4.24× | 42.43% / 4.24× | 42.50% / 4.25× |
| D5 | 39.74% / 3.97× | **42.08% / 4.21×** | 41.85% / 4.18× | 41.80% / 4.18× |
| D8 | 40.38% / 4.04× | 43.03% / 4.30× | 42.70% / 4.27× | 42.49% / 4.25× |

正式模型D10的95%年份区块bootstrap区间约为 `40.48%–44.19%`。其D1只有
`1.09%`，远低于约10%的参考比例。这种从低分组到高分组的陡峭梯度说明ASPR适合
进行**优先级排序和候选富集**。

但Panel b不是概率校准图。D10的42.08%是“最高预测十分位中实际进入前10%的比例”，
不表示ASPR=90的论文一定具有42.08%的概率，也不能把不同十分位曲线直接解释为个体概率。

## 9. Panel c：精确的时间—领域OOF性能地形

### 9.1 Panel c是全图的主定量面板

Panel c同时展开四个分析维度：

- 行：D3、D5、D8；
- 列：Strict 7、Full-text 16、Primary 154、Broad T0 221；
- 横轴：连续三年后向窗口的结束年；
- 纵轴：12个论文领域；
- 单元颜色：该单元中OOF预测与实际扩散的Spearman相关。

显示年份 `y` 对应的不是单一年份，而是：

```text
ρ(y) = Spearman(
  OOF prediction,
  realized diffusion
  for papers published in y−2, y−1, y
)
```

因此，第一列结束年1988对应1986–1988论文。三年窗口是明确的统计汇总单位，
不是图形插值或平滑。

### 9.2 12个领域为什么按这个顺序排列

所有Panel c、d、e共享同一领域编号。顺序按正式D5 × Full-text 16在可靠三年窗口中的
平均Spearman从高到低排列，只改变显示位置，不改变任何数值：

| 编号 | 图中简称 | 完整领域 | 平均可靠D5 ρ |
|---:|---|---|---:|
| 1 | Eco/evol/micro | Ecology, evolution & microbiology | 0.7772 |
| 2 | Chemistry | Chemistry | 0.7769 |
| 3 | Earth/climate | Earth, climate & environment | 0.7424 |
| 4 | Astronomy | Astronomy & space | 0.7422 |
| 5 | Life/molecular | Life & molecular sciences | 0.7319 |
| 6 | Eng/energy | Engineering & energy | 0.7288 |
| 7 | Materials | Materials & nanoscience | 0.7263 |
| 8 | Physics | Physics | 0.7163 |
| 9 | Clinical | Clinical health | 0.7152 |
| 10 | Neuroscience | Neuroscience | 0.6816 |
| 11 | CS/AI | Computer science & AI | 0.6604 |
| 12 | Math/stat | Mathematics & statistics | 0.5195 |

这种排序让相近性能形成较集中的色带，减少视觉杂乱。它不意味着相邻领域在知识空间中
距离更近，也不表示该排名是领域“质量”排名。

### 9.3 蓝—红绝对性能色标

12张热图共享同一绝对Spearman色标：

```text
蓝 → 青 → 浅黄 → 橙 → 红
低表现                         高表现
```

主色标聚焦于 `0.68–0.82`，中点为 `0.75`。这样设置是为了让约0.734–0.769之间的
差异在印刷尺寸下仍能辨认。色卡两端的小三角表示存在低于0.68或高于0.82的真实值：
这些值使用端点颜色显示，但底层数值没有被删除或改写。

全部可靠单元的真实范围约为 `0.1142–0.8788`。因此：

- 深蓝单元可能远低于0.68，不能只凭颜色读出精确值；
- 深红单元可能高于0.82；
- 精确比较必须读取 `performance_landscape.csv`；
- 色标适合观察主性能区间内的结构，不适合从端点颜色估算极值。

### 9.4 灰色和近白色区域分别表示什么

工具栏区分三种非性能状态：

| 状态 | 触发条件 | 含义 |
|---|---|---|
| `structural n < 30` | 三年领域窗口有效对少于30 | 样本不足，不计算正式相关 |
| `constant ranks; ρ undefined` | 预测或标签没有足够排序变化 | Spearman数学上不可定义 |
| `outcome not yet mature` | 窗口结束年超过该horizon成熟边界 | 未来标签尚未完整，不能评价 |

当前完整补抓后，Panel c有 `4,704` 个可靠成熟单元、`336` 个未成熟单元，
`n < 30`和`ρ undefined`单元均为0。336个未成熟单元由以下区域构成：

- D5的2021–2022：`2年 × 12领域 × 4集合 = 96`；
- D8的2018–2022：`5年 × 12领域 × 4集合 = 240`。

因此，当前图中真正的灰色末端区域主要表示“结果尚未成熟”。热图中的浅黄或近白色
性能格则通常表示 `ρ` 接近色标中部0.75，不能误读为缺失。

### 9.5 2014年后的半透明灰带

所有热图从2014年开始覆盖一层透明度很低的灰带，用于提示较新的发表时期和后段
forward-test区域。它不是缺失标记、不是显著性标记，也不改变底层Spearman值。

由于灰带会轻微降低2014年后颜色饱和度，比较灰带前后单元时应参考共享色标和原始表，
不能把颜色变淡全部解释为性能下降。

### 9.6 精确渲染与正式模型标记

Panel c使用逐格 `pcolormesh` 精确绘制：

- 不进行双线性、高斯或空间插值；
- 不填补缺失值；
- 每个格边界对应一个真实的领域—三年窗口统计量；
- 四套集合在同一horizon/domain/year单元使用相同论文和标签。

D5 × Full-text 16单元的琥珀色边框、星号和 `Official ASPR model` 文本仅标明正式
模型身份。它不是显著性检验结果，也不是说该面板中的每一个局部格都优于其他集合。

### 9.7 正确观察Panel c的方法

建议按三步阅读：

1. **先横向看同一行。**比较同一horizon下四套集合是否形成相似地形；若相似，说明
   主信号对指标集合扩展具有稳健性。
2. **再纵向看同一列。**比较D3、D5、D8随窗口延长是否增强或减弱；不能把不同窗口
   直接当作同一个标签的重复测量。
3. **最后看领域与年份色带。**识别稳定高区、低区和时代变化，再用Panel e判断这些
   差异是否来自新增指标。

## 10. Panel d：正式模型的三维性能山脉

### 10.1 为什么Panel d存在

Panel c负责精确读数，但12张小热图不容易让读者迅速形成正式模型整体地形的直觉。
Panel d把D5 × Full-text 16的成熟性能矩阵转为一整片半透明三维山脉，承担的是
**视觉解释**，不是新的统计检验。

### 10.2 三个轴和颜色

| 元素 | 含义 |
|---|---|
| x轴 | 三年窗口结束年，约1988–2020 |
| y轴 | Panel c的12个离散领域编号；只稀疏显示1、4、8、12 |
| z轴 | OOF Spearman ρ，显示范围0.28–0.90 |
| 曲面颜色 | 与Panel c一致的蓝—青—黄—橙—红性能色谱 |
| 曲面高度 | 局部OOF Spearman的视觉高度 |
| 底面轮廓 | 若干ρ等值线向底面的轻量投影，帮助辨认峰谷走向 |
| 半透明表面 | 让重叠山体和底面轮廓仍可见，不表示不确定性大小 |

z轴不从0开始，因此山体起伏被有意放大以便观察。不能用峰高的视觉比例判断“某领域
性能是另一领域的两倍”；精确值必须回到Panel c或底层数据表。

### 10.3 插值究竟做了什么

Panel d采用两步视觉插值：

1. 每个领域内部只在首个和末个可靠观测年份之间线性补齐内部缺口；
2. 在共同成熟年份范围内，对“领域显示序号 × 年份”网格做平滑曲面插值。

它不会向某领域真实观测端点之外外推，也不会延伸到D5未成熟的2021–2022。

必须特别注意：12个领域是**分类变量**。跨领域曲面只是为了把按性能排序的离散ridge
视觉连接成山脉，不表示领域1与领域2之间存在可度量的连续科学距离，也不支持读取
两个领域之间虚构的“第1.5领域”数值。

### 10.4 外侧领域标签、箭头和峰值圆点

面板自动选择正式模型可靠窗口平均Spearman最高的三个领域：

1. Ecology, evolution & microbiology；
2. Chemistry；
3. Earth, climate & environment。

标签放在山体左右外侧，避免遮挡曲面；细箭头指向该领域插值曲线的峰值位置，峰值处用
白心深边圆点标出。这里的领域是按固定统计规则选出，不是人工挑选“最好看的山峰”。

箭头所指的是曲面中的局部峰值，不是总体OOF值，也不是该领域最重要的论文。

### 10.5 Panel d能与不能告诉我们什么

它可以帮助观察：

- 正式模型高性能区域是否形成持续山脊；
- 不同领域的峰谷大致出现在哪些时期；
- 最近成熟年份是否出现共同变化。

它不能用于：

- 精确读取某格的ρ；
- 判断相邻领域之间的连续关系；
- 代替Panel c检查缺失、成熟边界或局部异常；
- 把插值表面当作新增观测数据。

## 11. Panel e：更宽指标集合的边际价值

### 11.1 三张差值热图

Panel e固定D5任务，并对每个领域—三年窗口逐格计算相邻集合差值：

```text
Δ1 = ρ(Full-text 16) − ρ(Strict 7)
Δ2 = ρ(Primary 154) − ρ(Full-text 16)
Δ3 = ρ(Broad T0 221) − ρ(Primary 154)
```

比较双方使用相同论文、相同标签和相同窗口，因此差值反映的是特征集合扩展的局部表现
变化，而不是样本组成变化。

### 11.2 图中每个细节

| 视觉元素 | 含义 |
|---|---|
| 三列标题 | 候选集合减去紧邻的较小基线集合 |
| `Median Δρ` | 全部可靠D5领域—年份单元的中位相关差 |
| `% positive` | 可靠单元中 `Δρ > 0` 的比例 |
| 行号1–12 | 与Panel c左侧domain order完全相同 |
| 横轴年份 | 与Panel c相同的三年窗口结束年 |
| 蓝色 | 加入该层指标后局部Spearman下降 |
| 白色 | 差值接近0，不是缺失 |
| 橙红色 | 加入该层指标后局部Spearman提高 |
| 共享色标 | 三图都固定在 `−0.08–+0.08`，严格以0为中心 |
| `▲/▼` | 真实差值超出±0.08显示范围；三角方向表示正/负 |
| 灰色末端 | D5结果尚未成熟 |

Panel e与Panel c一样使用精确逐格绘制，不进行插值。超范围值只在显示时压到色标端点，
真实差值仍保存在数据表中。全图共有4个超范围单元，已用三角披露。

### 11.3 三组增益的精确摘要

每个比较有 `396` 个可靠单元，即 `12领域 × 33个成熟结束年（1988–2020）`：

| 指标扩展 | 中位Δρ | 正增益比例 | 10%分位 | 90%分位 | 最小值 | 最大值 |
|---|---:|---:|---:|---:|---:|---:|
| Full-text 16 − Strict 7 | **+0.0102** | **76.0%** | −0.0097 | +0.0316 | −0.0672 | +0.1807 |
| Primary 154 − Full-text 16 | +0.0040 | 63.6% | −0.0188 | +0.0220 | −0.0537 | +0.0475 |
| Broad T0 221 − Primary 154 | +0.0005 | 54.5% | −0.0060 | +0.0087 | −0.0438 | +0.0873 |

### 11.4 科学解释

从Strict 7扩展到Full-text 16产生最广泛、最一致的正增益，说明严格核心之外的高证据
全文指标确实补充了可泛化预测信息。

继续扩展到154和221后，中位增益迅速接近零，且正负单元更加交错。这支持
“预测饱和”解释：更宽的代理覆盖仍可能在特定领域或年份有用，但没有形成稳定、普遍的
额外收益。

Panel e解释的是**局部边际价值**，不是新的特征选择程序。不能根据某个蓝格就从冻结
集合中删除相应指标，也不能根据某个橙格建立领域特定集合而不进行新的外部验证。

## 12. 五个面板合在一起的完整论证

整张图的论证不是“模型相关系数很高”这么简单，而是一个闭环：

1. **Panel a建立可部署对象。**发表时指标经过固定HGB模型形成raw score，再转换成
   可交流的0–100 ASPR score。
2. **Panel b建立实际筛查价值。**高分组不是只在平均相关上更好，而是明显富集真正的
   未来高扩散论文。
3. **Panel c排除单一平均值掩盖问题。**性能在12领域、连续年份、三个窗口和四套集合中
   被逐格展开，能够看到稳定结构与异质性。
4. **Panel d把正式模型的高维矩阵转成直觉。**山脊说明性能不是一个孤立峰值，但插值
   只服务视觉解释。
5. **Panel e解释为什么正式集合停在16项。**严格7到全文16有广泛收益，再扩大到154和
   221的边际价值接近饱和。

组合后的中心结论是：

> 一套由文献证据冻结、仅使用发表时信息的紧凑指标集合，可以在严格前向时间测试中，
> 对论文未来科学吸收与跨领域扩散进行有意义的排序；这种能力跨窗口、年份和领域可见，
> 且并不依赖无限扩充代理指标。

## 13. 最常见的误读与正确说法

| 容易误读成 | 正确解释 |

## 14. 研究意义

### 14.1 从回顾性评价转向发表时观察

传统影响评价高度依赖多年后的引用累积。ASPR尝试在论文刚发表、未来结果尚未出现时，
利用可审计的T0信息产生前瞻性排序，从而支持更早的研究发现、跟踪和资源配置研究。

### 14.2 把“潜在影响”拆成吸收与扩散

两部分模型避免把“完全未被后续工作吸收”和“已被吸收但扩散较窄”混为同一回归问题。
这使得分数更接近科学传播过程：先发生吸收，再讨论吸收后的跨领域广度与均衡度。

### 14.3 证明证据质量可能比指标数量更重要

Full-text 16在所有三个窗口都取得最高总体OOF Spearman，而154和221没有稳定超越它。
这说明创新不在于简单堆叠大量代理，而在于把高证据、T0安全、机制互补的指标组织为
紧凑集合，并用严格时间外验证检验其增量价值。

### 14.4 将总体性能拆解为可审计地形

单一总体相关可能掩盖领域失效、年代漂移或样本稀疏。Panel c和e把总体结果展开为
领域—年份单元，使读者能够区分：

- 稳定的跨领域信号；
- 领域和年代异质性；
- 指标扩展的局部收益与局部损失；
- 真正不可计算与尚未成熟的区域。

## 15. 结论边界与仍然存在的不确定性

1. **预测不等于因果。**模型无法证明某个T0指标造成后续扩散。
2. **扩散不等于所有形式的科学价值。**重要但小众、长期兑现或负结果论文可能被低估。
3. **数据来源有限。**当前正式宇宙来自三个Nature Portfolio来源，跨出版社、语言和更广泛
   期刊体系的外部有效性仍需验证。
4. **标签依赖未来施引者taxonomy质量。**分类不完整的正uptake论文保持缺失；虽然没有被
   错写成0，但缺失机制仍可能带来选择性。
5. **百分位参考会随时代漂移。**当前ASPR使用成熟D5参考群体；未来部署需要监测输入分布、
   原始预测和分位映射是否漂移。
6. **局部相关具有抽样波动。**三年窗口与n≥30门槛提高稳定性，但领域—年份格仍不应被当作
   确定的领域常数。
7. **Panel d是解释性表面。**跨领域插值不增加数据，也不应成为定量结论来源。

## 16. 后续实验如何延续Fig. 3的思路

后续实验应保留四条不可退让的原则：

```text
T0输入边界
＋ 结果盲冻结特征
＋ 严格前向时间测试
＋ 明确区分精确证据图与视觉解释图
```

### 16.1 优先级最高：跨来源外部验证

在非Nature Portfolio期刊或独立数据库上冻结当前D5 × Full-text 16模型，直接评估：

- 总体与分领域Spearman；
- D10实际前10%命中率与lift；
- ASPR分位校准漂移；
- 与Panel c相同的领域—年份地形。

不得先在外部集上调参再称其为外部验证。若需要重训，应把“冻结迁移评估”和“外部域重训”
分成两个实验。

### 16.2 真正前瞻性的冻结队列

对2023年以后论文在发表时生成并封存 `raw_prediction_score` 与 `aspr_score`，等待D3/D5
结果成熟后再开启标签。这是比历史OOF更接近真实部署的检验。

### 16.3 模型与分数漂移监测

按出版年持续监测：

- 16项输入的缺失率和分布；
- raw score分布；
- ASPR百分位占比是否异常集中；
- D3先行标签与后续D5结果的一致性；
- 各领域D10 lift和Spearman是否跌出历史范围。

### 16.4 领域异质性的机制解释

Panel c显示领域差异，但不能说明原因。后续可在不改变正式分数的前提下，研究：

- 哪些T0指标在低性能领域缺失或分布压缩；
- 数学、CS/AI等领域的引用与taxonomy机制是否不同；
- 领域内校准是否改善绝对风险解释，但不损害统一排序；
- 领域样本量、来源构成和发表年代能解释多少性能差异。

### 16.5 新指标必须建立新版本

不得静默修改当前 `7/16/154/221`。若Fig. 1或后续证据发现新机制，应建立
`evidence_derived_v4`及新的冻结集合，并以同样的前向OOF协议与v3比较。这样才能区分：

- 原结论是否稳健；
- 新证据是否带来真正增量；
- 改善来自特征，还是来自样本、标签或模型变化。

### 16.6 ASPR在后续图中的合适角色

ASPR可以作为：

- 论文级前瞻性排序变量；
- 高分/低分分层变量；
- 候选论文筛查或案例抽样依据；
- 与后续真实扩散、知识图谱变化或专家判断比较的基线预测器。

ASPR不应直接作为：

- “创新论文”监督真值；
- 因果处理变量；
