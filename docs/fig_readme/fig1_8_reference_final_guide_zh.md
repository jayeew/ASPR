## 贯穿全文的几个定义

- **Claim／贡献主张**：带具体研究对象、条件和范围的科学陈述。FINDING、METHOD、MECHANISM、RESOURCE、THEORY 是角色标签，不是创新等级。
- **历史先例与相关背景**：GEAR 需要比较具体内容、证据和适用范围。语义相似、同社区或存在引用路径均不足以单独认定直接先例。
- **局部插入与联合图**：前者针对一条贡献的保留历史邻居；后者在多个贡献的去重邻域并集上重算。目标之间不会仅因同属一篇论文而新增边。
- **论文宏平均**：先计算每篇论文的比例，再让每篇论文等权参与平均；不等于把全部主张或回答要点混在一起求比例。
- **百分点（pp）**：例如 80%→90% 是增加 10 个百分点；不能写成“提高 10%”来替代这一差值。
- **区间、缺失与未决**：图中的重抽样区间描述样本汇总不确定性，不能覆盖模型评价的全部误差。技术缺失保留缺失；合理保留、科学未决、不可核验和错误分别解释。

特别注意：图中精确率、覆盖率和报告质量评分是**分析产物的评价指标**，当前运行时不输出论文数值新颖度评分。

**整图讲解：** 本图介绍论文引用网络与科学主张网络如何相互对应，并用四个真实案例展示新主张进入历史邻域后的不同结构表现。先看 a 理解两层网络，再看 b 的前后对照，最后用 c–e 理解总体规模、社区和关系类型。

![Fig1 最终版预览](/home/jayee/workspace/ASPR/outputs/fig1-8_reference_final_20261004/previews/Fig1.png)

**本图要讲清楚的关系。** 论文引用图提供“哪些文献发生过引用接触”的背景，主张图提供更细粒度的语义邻域。四个插入案例分别突出语义延续、社区组合、角色交织和连通变化；它们是从实际材料中挑选的解释性案例，不是四类已验证创新，也不用于估计这些结构在全部论文中的发生率。

**图例读法。** a/b 中颜色表示社区，节点形状表示贡献角色；同一颜色可以包含不同角色，同一角色也可以分布在不同社区。目标到父论文的跨层连线表示归属。网络布局主要服务于展示，图面距离没有对应科学相似度的刻度。

## Fig2｜GEAR–Graph 的证据分析框架

**D1–D14 的计算范围。** 此处所有数字都属于 X。D3 采用按余弦相似度形成的社区权重比例 `pₖ`，计算 `1 / Σ pₖ²`，即加权逆 Simpson 有效数；D7 为 `1 − max(pₖ)`。D8 是跨角色邻居**数量**，并非 Fig1 Case C 的跨角色**比例**。

X 的 10 个历史邻居最多有 45 条无向邻居间边，D9≈0.044 对应 2 条骨架边。D10=7 表示局部分量数量减少 7；D11=43 表示历史节点对的新增可达数。邻居数、边数、分量数和节点对数是四种不同单位。

D12–D14 的零值限定在保存的父论文引用记录内；不能写成“作者从未接触这些知识”。D5=0 则有更具体的覆盖依据：所涉及五社区的十个无序配对都能在当前历史配对表中找到。

### Panel d｜来源支持与原始可追踪性

**Panel 讲解：** 本 panel 将“事后核验有支持”与“原报告已经充分给出依据”分开，并展示未核实、矛盾及常见可靠性问题。两种比例共用待核验断言分母，原始可追踪 T 是有支持 S 的子集。

| 子图 | 说明了什么、怎么看 |
|---|---|
| d1：S 对 T 六边形密度图 | 横轴 T 为原报告已充分提供依据且核验成立的比例，纵轴 S 为经来源核验支持且范围正确的比例。六边形深浅表示观测数，彩色符号为方法均值，越靠对角线上方表示事后支持与原始依据之间差距越大。 |
| d2：支持状态堆叠条 | 各方法按论文宏平均分成支持、部分支持、不可核验和矛盾四类。灰色不可核验不等于已证伪，右侧 n 是该方法可用论文数。 |
| d3：可靠性问题气泡矩阵 | 五行分别是无依据确定断言、错误先例、错误首创、语义关系因果化和遗漏范围，气泡越大表示出现该问题的报告比例越高。它计是否出现问题，不是逐条错误总数。 |
| d4：S−T 差距累积分布 | 横轴为支持与原始可追踪的差值，纵轴为差值不超过该阈值的累计比例。曲线越靠左表示更多报告差距较小，zero 给出差值为零的比例。 |

**Panel d 的两个分母。** 对同一报告，`S = 有来源支持且范围正确的断言数 / 待核验断言数`；`T = 原报告已经充分提供依据且经核验成立的断言数 / 同一待核验断言数`。因此 `T ≤ S`，右下方 T>S 区域按定义不可行。S−T 小只表示事后支持与原始依据较接近，若 S、T 都低仍不能称为高质量。

d2 的“支持”状态与 d1 的 S 也不必完全相等：S 还要求范围正确。d3 则按“某份报告是否至少出现该类问题”计比例；一份较长报告中出现一处错误，也会计入该行，不能读成所有断言都出错。

这一组结果使 Fig3 的结论更具体：Full 提高了有据贡献覆盖和部分报告评价指标，同时仍存在断言层面的支持与范围问题。

### Panel b｜论文层面的知识结构

**Panel 讲解：** 三个年度子图使用相同坐标：横轴 D 是已分配社区的先行邻居有效社区数，纵轴 J 是非空贡献邻域对的平均 Jaccard 重叠。每点一篇论文，越右表示历史社区权重越分散，越上表示同篇不同贡献共享历史邻域越多。

| 子图 | 说明了什么、怎么看 |
|---|---|
| 左：2023，n=5,491 | 展示 2023 年具有两项可用坐标的论文分布。语料从 2023 年起，早期可用先行背景较短，不能把与后两年的差别简单归因于科学变化。 |
| 中：2024，n=9,105 | 展示 2024 年论文在相同 D–J 坐标中的位置。按同色同形比较期刊分布，同时留意样本量和历史可用范围不同。 |
| 右：2025，n=9,748 | 展示 2025 年的可用论文，三图合计 24,344 篇。右下、左上等位置分别组合了社区分散与邻域重叠两种属性，不是高低创新区。 |
| 顶部期刊图例 | 颜色与形状共同识别期刊，Nature Communications 点小、透明且先绘制，其余刊后绘制以便看清。点大小和覆盖先后是可读性设置，没有科学量含义。 |

**Panel b 两个轴的精确定义。** 先把同篇贡献的合格历史邻居合并成去重并集；对已分配社区的历史节点，令 `pₖ` 为该社区节点数占已分配节点总数的比例。横轴 `D = exp(−Σ pₖ ln pₖ)`，即 Shannon 熵的有效数，**不按余弦加权，也不重复计共享节点**。它不同于 Fig1/2 按相似度加权的逆 Simpson 有效社区数，不能直接横向比较数值。

对任意两条具有非空邻域的贡献，计算 `Jaccard(Nᵢ,Nⱼ)=|Nᵢ∩Nⱼ|/|Nᵢ∪Nⱼ|`，再对所有有效贡献对算术平均，得到纵轴 J。至少需要两个非空邻域；空邻域不以零分塞入平均。未分配社区节点不作为一个虚构共同社区，若没有已分配节点，D 无定义。

右下角表示保留背景涉及较多有效社区、同篇贡献之间较少共享邻居；左上角表示社区集中而共享较多。这是两种结构属性的组合，没有标定成创新优劣象限。

**Panel 讲解：** 每行展示一种期刊中各论文“被同篇至少两条贡献共享的历史节点比例”，合计 24,345 篇可用论文。点越靠右表示共享历史背景比例越大，黑线是四分位范围、白刻线是中位数，二者不是置信区间。

**Panel c 的共享比例与 b 的 J 也不同。** c 的分子是并集中“连接本篇至少两条贡献”的唯一历史节点数；分母是全部唯一历史邻居数。b 的 J 是逐贡献对 Jaccard 的平均。三条贡献时，一个节点被两条共享和被三条共享，在 c 都只算一个共享节点，却会不同地影响多个贡献对的 Jaccard。
