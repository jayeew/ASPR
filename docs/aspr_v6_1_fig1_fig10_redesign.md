# ASPR v6.1 实验1–10与 Fig.1–Fig.10 重设计及重跑说明

## 1. 本轮改造结论

本轮没有继续沿用旧版“方法架构、预测结果、外部证据和应用案例混排”的图组，
而是围绕一个可审稿的问题重新组织十个实验：

> 仅用论文发表时可获得、具有来源依据的五类创新观察信号，能否在严格时间
> OOF 中预测论文未来五年的学术传播与跨领域扩散，并在时间、学科和控制方案
> 改变后保持稳定？

新版图组遵循以下分工：

1. Fig.1–Fig.3 定义研究对象、指标选择证据链和测量质量；
2. Fig.4 给出唯一主结果；
3. Fig.5–Fig.8 检查窗口、时间、学科和去控制后的稳健性；
4. Fig.9 解释五个观察角度的互补预测信息；
5. Fig.10 汇总敏感性、接受门和精确复跑证据。

旧版结果没有被覆盖。新版制品位于
`outputs/common/new/baseline_suite_r1/`，并绑定独立运行清单与哈希。

## 2. 数据、标签与共同实验约束

- 研究队列：118,059 篇 Nature 论文，覆盖 12 个自然科学大类。
- OOF 队列：101,379 篇论文，预测年份为 1986–2017。
- 原始数据：仅复用冻结的 Nature v5/v6.1 论文、引用关系和本地 OpenAlex
  快照；本轮没有下载新的实验原始数据。
- 指标池：50 个文献候选，经不查看预测结果的规则筛选后，冻结 8 个主指标。
- 主窗口：D5，即论文发表后第 1–5 年。
- 主评价量：把六个互斥时间测试折合并后的 Spearman 相关系数。
- 主比较：`最终8个创新指标 + K1` 对 `K1`。
- 模型：固定 medium 两部分模型。第一部分预测未来是否至少被引用一次，第二
  部分对有未来引用的论文预测扩散程度；两部分合成为期望扩散分数。
- 防泄漏：每折只使用测试论文之前的年份训练，缺失处理、类别编码、标签分位
  坐标和校准均只在训练折内拟合。

标签不是“创新真值”，也不是原始引用次数。无未来施引时标签为 0；有未来
施引时，将未来施引论文的 field/subfield/topic 覆盖广度和 field/topic
均衡度放入训练折坐标系，得到未来传播与跨领域扩散分数。因此主 Spearman
回答的是：模型能否把未参与训练的论文按未来扩散程度正确排序。

六个时间折固定为：

| 折 | 训练论文年份 | 测试论文年份 |
|---|---:|---:|
| 1 | ≤1985 | 1986–1999 |
| 2 | ≤1999 | 2000–2004 |
| 3 | ≤2004 | 2005–2009 |
| 4 | ≤2009 | 2010–2012 |
| 5 | ≤2012 | 2013 |
| 6 | ≤2013 | 2014–2017 |

## 3. 五个观察角度与最终指标

| 观察角度 | 最终主指标 | 在体系中的含义 |
|---|---|---|
| A1 组合稀有性 | 参考重叠新颖度 | 论文参考知识与既有论文参考集合的重叠程度 |
| A2 非典型性与常规性 | 组合常规性中位数 | 论文知识单元组合相对历史共现期望的常规中心 |
| A3 首次组合 | 首次来源组合占比 | 参考来源配对在论文发表前从未出现的比例 |
| A4 知识广度与均衡性 | 领域类别数、跨本领域参考占比、领域均衡度 | 论文调用多少类知识、是否跨越本领域、分布是否均衡 |
| A5 认知距离与整合 | 平均认知距离、Rao–Stirling 整合度 | 被组合知识之间的差异程度及差异加权整合 |

指标的原始公式、论文级应用来源、角色和逐项纳入/排除理由保存在
`configs/innovation_candidate_registry_v6_1.json`；完整证据说明见
`docs/aspr_v6_1_indicator_evidence_map.md`。预测性能没有参与指标纳入。

| 实验 / 图 | 要回答的唯一问题 | 子图安排 | 本轮允许得出的结论 |
|---|---|---|---|
| Exp.1 / Fig.1 | 数据和标签究竟是什么？ | a 队列流；b 12大类构成；c 年份覆盖；d D3/D5/D8 标签分布 | 明确总体、OOF样本、时间范围和标签语义，不在此图展示模型优越性 |
| Exp.2 / Fig.2 | 为什么是这些创新指标？ | a 50→30→20→8筛选流；b 五角度内候选角色；c 主/敏感性候选门槛证据；d 8指标到5角度映射 | 指标来自注册候选池并按结果无关规则筛选，不是按 OOF 挑出的 |
| Exp.3 / Fig.3 | 8个指标是否可测、稳定且不完全重复？ | a 总体/最弱学科覆盖；b 参考重采样稳定性与精确公式一致性；c 指标相关矩阵；d 角度内外相关比较 | 指标通过覆盖、稳定、公式一致性和非退化检查；相关不等于严格重复 |
| Exp.4 / Fig.4 | 创新指标能否在 K1 之上提高 D5 排序？ | a 各模型 OOF 点估计；b 配对增量区间；c 预测十分位的高扩散论文比例；d 标签均值分离 | 这是唯一 D5 主结果；重点报告最终模型相对 K1 的配对增量 |

| Exp.6 / Fig.6 | 能否外推到严格更晚的论文？ | a 六折训练/测试时间线；b 各折性能；c 各折配对增量区间；d 按发表年漂移 | 六折点增量均为正且区间下界均大于0，同时如实展示时间异质性 |
| Exp.7 / Fig.7 | 结论能否跨越12个自然科学大类？ | a 各领域控制/全模型；b 各领域增量区间；c 纯创新/完整模型；d 样本量与增量 | 12大类全部保留；点增量12/12为正，区间下界11/12大于0 |
| Exp.8 / Fig.8 | 去除全部控制后还剩多少创新信号？ | a 总体模型比较；b 各折比较；c 纯创新预测十分位分离；d 与控制/全模型排序重叠 | 8个创新指标单独已有预测信号，但与 K1 联合表现最好 |
| Exp.9 / Fig.9 | 五个角度是否提供互补信息？ | a K1+单角度；b 单角度相对K1增量；c 全模型删一角度损失；d 各折删除效应 | 这是结果已知后的解释性消融，只量化预测互补性，不重新筛指标、不作因果解释 |
| Exp.10 / Fig.10 | 敏感性与复现证据能否支撑主张？ | a 控制集/模型敏感性；b 接受门余量；c 窗口、折、领域压力单元增量；d 审计与精确复跑 | 预设接受门全部通过，冻结输入和检查点可精确复跑 |

选择这些表现形式的原则是：计数和组成使用流程图或条形图；成对模型比较使用
点区间或 dumbbell；跨折、跨窗口的二维异质性使用热图；预测分层使用十分位图。
所有相关图的坐标轴均显示零线或完整比较范围，避免截轴放大微小增量。

## 5. 完整重跑结果

| 结果 | 数值 |
|---|---:|
| D5 最终模型 OOF Spearman | 0.7670 |
| D5 K1 控制模型 OOF Spearman | 0.6813 |
| D5 最终模型相对 K1 增量 | +0.0857 |
| 上述增量的95%配对 bootstrap CI | [0.0831, 0.0884] |
| D5 纯创新指标 OOF Spearman | 0.7073 |
| D3 / D5 / D8 相对 K1 增量 | +0.0725 / +0.0857 / +0.0894 |
| 时间折增量点估计为正 | 6/6 |
| 时间折增量95%区间下界大于0 | 6/6 |
| 学科增量点估计为正 | 12/12 |
| 学科增量95%区间下界大于0 | 11/12 |
| 预设接受门通过 | 5/5 |

五角度 D5 OOF 消融结果：

| 角度 | K1+该角度相对K1增量 | 从完整模型删除后的损失 |
|---|---:|---:|
| A1 组合稀有性 | +0.0158 | +0.0019 |
| A2 非典型性与常规性 | +0.0113 | +0.0001 |
| A3 首次组合 | +0.0039 | +0.0002 |
| A4 知识广度与均衡性 | +0.0830 | +0.0099 |
| A5 认知距离与整合 | +0.0713 | +0.0006 |

A4 和 A5 单独提供的排序信息最多，删除 A4 对完整模型影响最大。A2、A3 的
删除损失接近零，表示它们在当前模型中与其他角度高度冗余，而不是证明这些
理论维度不存在或应按结果删除。

## 6. 结论边界

本轮结果支持：

- 五类发表时创新观察信号能够预测未来学术传播与跨领域扩散排序；
- 该信号在控制发表年份、学科、载体、参考文献和团队规模等机会因素后仍有
  明确增量；
- 结果在三个未来窗口、六个时间折和十二个自然科学大类中总体方向一致。

本轮结果不支持：

- 把未来扩散标签称为论文创新性的直接真值；
- 把预测增量解释为创新指标对未来影响的因果效应；
- 因为某个角度消融损失小，就重新删除已经按文献和测量规则冻结的指标；
- 宣称十二个领域的统计证据完全同质，因为仍有一个领域的配对区间跨零。

## 7. 运行与制品

完整重跑命令：

```bash
python3 experiments/common/old/v6_1_figures_r1/run_all.py \
  --config configs/aspr_v6_1_figures.json \
  --output-dir outputs/common/new/baseline_suite_r1
```

60 个检查点；每个模型均覆盖同一批 101,379 篇 OOF 论文。全部十张图均同时
输出 PNG 和 SVG。
