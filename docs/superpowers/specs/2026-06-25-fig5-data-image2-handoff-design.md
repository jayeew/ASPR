# Fig. 5 Data Package and Image-2 Handoff Design

## Goal

Produce Fig. 5 in two layers:

1. A reproducible data package that computes the evidence and text used in the figure.
2. An image-2 handoff package that instructs a drawing model to render a publication-style four-panel figure closely matching the supplied reference image.

The Python code should prioritize auditable result data over deterministic final artwork. The final artwork may be generated by image-2, but all scientific claims, labels, rankings, scores, and card text must come from the generated data package.

## Figure Contract

The target figure is a four-panel publication graphic, not the older five-panel analytical layout:

- Panel a: forecast setting, historical graph on the left, arrow in the center, future window with question-mark foci on the right.
- Panel b: top predicted research foci, with a word-cloud style left block and a horizontal ranked bar chart on the right.
- Panel c: predicted frontier landscape topic map with historical topic nodes, predicted focus bubbles, labels, and a small size/color legend.
- Panel d: four representative key innovation cards with rank badges, icon type, predicted role, and reason text.
- Bottom strip: take-home message.

Backtesting may remain in tables or future audit outputs, but it is not part of the main image-2 figure.

## Data Flow

`build_fig5_plot_data.py` loads Fig. 3 scores and Fig. 3 input tables, normalizes paper/topic ids, aggregates pre-cutoff topic signals, ranks forecast foci, selects representative seed papers, and writes the base/derived/config CSV and JSON files.

A new handoff builder reads those generated tables and creates the image-2 prompt, panel text JSON, visual notes, and layout draft. It must not recompute rankings independently.

## Validation

Implementation is complete when:

- The data builder runs with the default Fig. 3 paths in this workspace.
- The handoff builder runs from the data package and writes all handoff files.
- The panel text JSON uses the same top focus labels and scores as `fig5_panel_b_top_focus.csv`.
- The Panel d card text uses rows from `fig5_panel_d_cards.csv`.
- The prompt states that image-2 must preserve exact figure text and not invent new scientific claims.
- Existing unrelated working-tree changes are left untouched.
