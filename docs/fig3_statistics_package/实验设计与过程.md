# 实验设计与执行过程

## 研究目的与单位

比较六种论文创新分析方法在历史增量判断、证据支持、范围限定、审稿问题覆盖、有效科学信息、融合行为和整体报告偏好上的表现。输入为既定100篇论文及已有审稿记录；稿件和审稿意见不是新增采集的人类验证。论文是统计重抽样单位。共享贡献是作者贡献抽取对象，核心贡献是评价对象，两者数量及身份不能混用。

## 六种方法

| 文件标识 | 方法 | 生成输入及科学路径 |
|---|---|---|
| direct_a | Direct-A | 只读论文正文；分片阅读、整篇分析、报告，不读共享贡献、审稿意见、其他方法判断 |
| gear | GEAR | 共享贡献、独立历史检索与来源阅读，逐贡献比较、范围判断、报告 |
| graph | Graph | 共享贡献、历史图临时插入及事实计算，单贡献与union邻域joint分析、报告 |
| fusion（报告目录full） | Full | 新GEAR与Graph结果，逐贡献融合及整篇joint综合 |
| eacl | EACL-adapted | 独立贡献与引用抽取、检索排序、历史比较、报告 |
| reviewgrounder | ReviewGrounder-adapted | 独立正文分析与草稿、文献与结果整合、报告 |

GEAR/Graph在融合前不读取彼此判断。外部基线不是共享贡献对照。历史图不被修改；临时插入最多10个合格邻居，余弦严格大于0.5，排除目标论文及不合日期的来源。语义邻近和论文引用路径不是贡献级因果或先行证据。所有六方法报告本轮新生成。

## 模型和资源设置

生成式调用均为独立Codex CLI会话，模型 `gpt-5.6-luna`，不使用OpenAI API替代。共享贡献、报告生成、抽取、聚类、偏好与中立分片阅读主要为high；审稿分段与语气medium；历史参考、科学核验、创新评价、质量、审稿比较、融合效果及复核xhigh。具体角色映射见 `config.py`。本地Qwen3-Embedding-4B负责嵌入，OpenScholar排序模型负责重排，图计算本地完成；这些不是生成模型评委。

正文块最多3000字符；研究材料目标8000、上限12000字符；完整可控请求含指令和schema上限24000字符、64000 UTF-8字节。超限先分片中立阅读再综合，不截断尾部。CLI初始16并发、上限64，网络队列16，GPU共享队列，保留4GiB内存余量；按调用完成事件调整并发。局部超时600秒、综合900秒。并发上限不是始终达到的实际并发。总token包括提示、材料、CLI上下文及输出，不能由材料字符限制推算费用。

## 01：材料准备与六方法报告

100篇重新抽取共享贡献；审稿分段、问题整理、语气及轮次变化；六方法独立生成600份报告；建立中立证据来源池。共有1400个顶层阶段任务，任务内仍有多次模型调用。正文块、来源别名和定位可共享，独立方法判断不可互相替代。共享贡献实际719条，不使用历史固定660条。

## 02：评价

4500个顶层阶段任务包含：核心100、历史参考100、报告抽取600、支持性600、创新判断600、质量清单100、五维质量600、真人问题比较600、聚类100、融合100、偏好1000。顶层任务数量不等于底层CLI调用次数。

- 历史参考R：围绕核心贡献整理历史覆盖、差异与必要范围；证据不足保留不足。
- 报告预测P及科学判断V：抽取报告观点并与R/稿件/来源比较，评估有效增量、范围与过度主张。
- 来源核验：断言支持程度、限定是否正确、原报告是否已提供依据及错误类别。
- 质量：贡献忠实性、历史增量、知识关系、范围/不确定性、整篇综合五维，各0—3分，不合成总创新分。
- 真人问题：报告对审稿问题及理由的回应范围、立场和科学分歧；沉默不当作错误或已解决。
- 聚类/融合：支持的实质信息按科学信息聚类，比较分支并集与Full保留/新增；纠错、未传播、传播和未知分开。
- 偏好：Full与五个对照在每篇上分别AB、BA两顺序，合计1000次顺序判断。四维偏好与整体偏好独立。

02执行中进行了合批与续跑优化：保留已有判断，新问题按共享证据合批；部分问题用中立问题卡、部分沿用原始问题材料。最终schema统一，但不能声称所有历史调用的材料组织完全相同。普通日志中的失败尝试与实际token仍计入总消耗。发现的核心ID错误/漏答仅对缺失核心补问，明确保留核心定义、参考和预测，未向首轮评委展示03答案。

## 03：盲法复核与控制

按领域比例、固定种子20260922选20篇。每方法最多抽2条来源核验、前2个核心创新评价、2个随机真人问题，实际222+204+240=666对象。复核隐藏首轮标签和理由；同方法同类别预算内合批。真人问题保留对应首轮原文/问题卡材料模式。独立复核不共享评判结论。不同标签才进行解释，解释不替换主实验结果。缺失首轮数据已补齐，原复核答案保留，666项现在均可比较。

每篇最多构造三类原版/修改版控制：引用错配、夸大首创、删除必要范围。先从真实报告断言按方法轮流选择少量候选，最多12条/7000字符；候选不足可缺少类别。原版/修改版独立评判，不展示修改类型、配对文本或预期答案。实际52对，8类未构造；这些控制衡量评委对特定构造错误的响应，不是外部人工金标准。

## 04：统计与导出

读取最终结果，生成论文级指标、方法汇总、Full减各比较方法的配对差、成本、复核覆盖与控制覆盖；10000次共享论文级bootstrap，种子20260922；40组件、8panel与420×760mm母版。04不调用模型。图例/名称展示Full，统计中 `fusion` 对应Full。本包只取无原文引文的统计表。

## 解释边界

所有来源辅助判断仍是模型判断；历史检索不完整不能证明首次，来源键存在不证明事实成立。复核一致率不是准确率，bootstrap区间只反映论文抽样变化。有效分母应逐指标读取；“文件齐全”不等于所有科学判断可判定。成本是运行尝试的累计值，不是一次理想无失败实验的预测值，也不是美元账单。
