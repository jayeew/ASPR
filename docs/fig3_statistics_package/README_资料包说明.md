# Fig.3统计与实验代码资料包

本包整理当前100篇论文实验的最终派生统计，附实验设计、执行过程、字段解释和相关源代码。**不包含论文/审稿原文、报告正文、证据引文、逐条模型回答、提示词请求记录、模型权重、历史图或嵌入资产。** paper_id只是跨表关联标识；论文级指标是计算结果，不是原始文本。

## 阅读顺序

1. `实验设计与过程.md`：实验对象、六方法、模型设置、01—04流程与解释边界。
2. `数据字典与统计口径.md`：分母、宏/微平均、区间、缺失、token与表格粒度。
3. `statistics/overview.json`：当前实际规模及消耗概况。
4. `statistics/summary.csv`：方法级指标和95%区间；`paired_differences.csv`：Full减各比较方法。
5. `statistics/paper_metrics.csv`：论文×方法×指标级详细数值。
6. `statistics/table_inventory.json`：全部统计表的列名和行数。
7. `code/`：保留仓库结构的实验脚本、运行模块、GEAR依赖代码、配置及离线测试。

## 当前数据规模

100篇论文、6种方法、600份报告；719条共享贡献（每篇最多8条）；157个核心贡献，对应942个方法×核心评价对象。偏好实验为500组Full与比较方法的配对、1000次AB/BA顺序判断。固定20篇复核含666个对象，全部可比较；最多60个控制配对，实际构造52对，8个类别/论文组合未构造，不冒充成功控制或失败科学判断。

本包不是600份报告的合订本。包含原文引文的c6/f5案例图，以及自由文本类别过多的e4/e5组件未复制；其余32个组件的数据表仅含统计值或类别。完整母版也未放入，因为其中包含原文案例。

## 使用方式

CSV为常见表格格式，统计主表使用UTF-8 BOM便于Excel打开；组件表为UTF-8。Python可用 `pandas.read_csv(path, encoding='utf-8-sig')`。空单元格表示未知/不适用，不能自动填0。overview与table_inventory为JSON。

已有统计表可以直接用于二次分析，无需模型或原始数据。仅凭此包不能重新生成全部科学判断：重跑01—03还需要原始输入资产、历史文献与图、嵌入/排序模型，以及可用的Codex CLI登录会话。本包有意不携带这些数据和凭证。

源代码在 `code/scripts/fig3_revision/`；配置路径仍是原工作区设置，迁移运行时需自行指定真实输入位置。打包脚本为 `package_statistics.py`，在具备原工作区结果时重新生成本包；它不调用模型。实验代码说明见 `code/figure_pipeline/fig3_revision/README.md`，字段结构见 `models.py`，公式以 `aggregate.py` 为准。
