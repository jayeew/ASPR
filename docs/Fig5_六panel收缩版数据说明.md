# Fig.5 六 panel 收缩版：数据与展示口径

本版采用最小新增数据方案，先交付数据，不画图。a 复用 Fig.4 既有评价；b/c/d/f 复用五篇核心样本；e 仅新增三篇既有报告的 H/J 评价。三个样本集合分别注明，不混成同一套评价或独立确认试验。

总标题建议：**不同材料与配置条件下的判断可靠性及推理代价**。

## a｜观察领域中的表现差异

- 数据：95 篇非开发论文，生命科学39、物理工程35、医学13、地球环境8；固定比较 F（完整系统）与 E（仅 GEAR）。
- 展示：各领域 H/N/J/S/C 的 F−E 配对有据正确覆盖差异及论文级 bootstrap 95% 区间，旁列 F 绝对覆盖与实际有效论文数。
- 文件：`panel_a/domain_summary.csv`、`paired.csv`、`paper_metrics.csv`、`samples.csv`。
- 原指标为 `grounded_coverage`，必须标注“Fig.4 原评价口径”；不是 b–f 的新版 `q_fixed`。共有475个论文×方面槽位，其中451个适用且完整配对、24个不适用；没有以零值填补不适用项。
- 结论限于观察领域的表现差异，不推断未见领域泛化。

## b｜原文缺失敏感性

- 数据：五篇核心样本，F/E50，H/N；实际独立作品保留率约46.2%–50%。
- 展示：逐论文 F→E50 两端点，固定任务正确覆盖与可回答比例；旁列共同可回答要点上的配对变化。
- 文件：`panel_b/paper_metrics.csv`、`paired_answerable.csv`、`conditions.csv`。
- 两端点不称“完整分级退化曲线”。可回答性不同的任务分母需显式显示；没有共同可回答要点的配对不计零。

## c｜关键证据依赖

- 数据：同五篇，F/关键删除/非关键删除；每篇使用事先固定的同一 H 要点，删除作品数逐篇匹配。
- 展示：三列逐论文响应状态；区分有据正确、目标保留、错误或无据断言，以及实质回答但未完成目标/未充分落地的情况。并列关键删除的保留率与非关键删除的有害翻转率，后者只以 F 原本正确的目标为分母。
- 文件：`panel_c/target_parts.csv`、`target_transitions.csv`；支持组与资格条件在 `core_data/support_results`、`eligibility`。
- 关键/非关键匹配按作品数，非严格字符数匹配；未补证据恢复试验。

## d｜回答与保留的适用边界

- 数据：直接复用五篇、四条件、H/N 的104个固定适用要点。
- 展示：可回答性 × 响应状态计数矩阵；真实条件下的回答覆盖—已回答风险点，旁注合理/不必要保留的分母。
- 文件：`panel_d/decision_matrix.csv`、`response_matrix.csv`、`paper_metrics.csv`。
- 条件改变材料，不是拒答阈值扫描；不能把这些点连成平滑风险—覆盖曲线。参考未决、技术缺失、遗漏独立保留。若风险未决，使用空点估计和识别界限，不冒充置信区间。

## e｜参数与模型敏感性

- 数据：原探索名单最前面的三篇完整 F/K5/LUNA 报告，论文为 s41467-026-68332-4、s41467-026-68412-5、s41467-026-68427-y。按名单和报告可用性选择，不看得分。
- 展示：H（历史核对）与 J（联合贡献结构）的逐论文配对变化，分别比较 K5−F、LUNA−F；三篇全部展示，不以显著性检验代替描述。
- 文件：`panel_e/paper_metrics.csv`、`paired_fixed.csv`、`paired_answerable.csv`、`answer_parts.csv`。
- F 与 LUNA 使用同一材料参考；K5 使用其真实截断图对应参考。`material_checks.json` 核对原报告写作时的论文、图及历史原文与评价材料匹配。
- 新增仅9个H/J合并评价请求，失败也占预算；未生成报告。判别器为同一 gpt-6.1-sol，未新增独立模型复核，因此模型敏感性结论保留潜在裁判偏差边界。
- 未做重复运行、顺序重排或K3实验；本 panel 不叫“一般稳定性”。

## f｜固定材料下的推理代价

- 数据：五篇核心样本×四条件，逐报告追溯 GEAR、Graph、写作三阶段，合计60份成功调用记录。记录的模型输出与实际保存阶段产物匹配后才计入。
- 展示：输入/输出 token 与新版 H/N 正确覆盖的观测点，逐阶段 token 构成；时延仅在记录完整时单独展示。分别标明条件与论文，不拟合预算前沿。
- 文件：`panel_f/stage_costs.csv`、`cost_quality.csv`、`source_records/`。
- 成本为已采用成功推理阶段的消耗，不是整个实验账户支出；不含评价、失败重试、检索、建图及嵌入。输入 token 已含缓存输入，输出 token 已含推理输出，不重复相加；不同字段及不同模型的 token 不直接换算费用。
- `call_seconds_sum` 只是调用耗时之和。只有10/20份报告有完整生成墙钟记录，另5份缺失、5份仅有中断续跑片段；后两类的 `wall_seconds` 留空。
- 未新增低/标准/高预算实验，因此标题不用“预算最优前沿”或“端到端成本”。

## 文件使用与解释

主目录：`outputs/fig5_six_panel/`。`core_data/` 保存前一轮核心数据的完整快照；`panel_e/` 保存新评价输入、原始响应和对齐结果。逐要点证据可以追溯，原结果不覆盖。

b–f 的新版指标不合成总分。a 保留历史方法标签。H/N/J/S/C 为方面名称，实际数据中的 canonical aspect 名称保留不变。所有新增评价是模型判断，不称新增人类金标准；数据流程检查不等于科学正确性验证。旧 figure_pipeline 报告只能支持其实际生成路径，不直接证明当前 gear 默认运行时有效。

原大批次与定时监督保持暂停；本版完成即停止，不自动补跑其余条件。
