代码与输出目录，不修改旧实验制品。正式输出位于：

`outputs/common/new/base_suite`

```bash
python3 -m experiments.common.new.base.run_all \
  --config configs/aspr_v6_1_nature_figures.json \
  --output-dir outputs/common/new/base_suite
```

- 绘图底表 `panel_data/*.csv` 或 Parquet；

- 含输入、输出和图像资产 SHA-256 的 `run_manifest.json`；
- 单面板 PNG/SVG；
- 整图 PNG/SVG/PDF。

套件根目录另含十图 contact sheet、来源谱系、可发表性清单、图形类型审计、
实现偏差说明和草拟图注。

## 3. 当前主结果

- 最终八指标加 K1 模型的 D5 全时期时间 OOF Spearman：
  **0.7670**，有效论文 **101,350** 篇。
- 纯创新指标模型：**0.7073**。
- K1 控制模型：**0.6813**。
- 最终模型相对 K1 的 Spearman 增量：**+0.0857**。
- OOF 预测最高十分位中，真实 D5 高扩散论文富集：**4.02 倍**。
- Fig.5 三次历史回测中，ASPR 平均 Precision@10 为 **0.13**，
  平均 NDCG@10 为 **0.61**；结果并非在每个截断、每项指标上都优于基线。

## 4. 未伪造的缺口

1. Fig.4 的 90 行盲评为空，因此仅展示已锁定的低/中/高抽样框架，
   其余面板拒绝生成效度值。
2. Fig.6 注册实验只有 80% 参考文献重采样，没有将 75%、50%、25%、
   10% 缺失剂量插值为“实验结果”。
3. Fig.7 本地冻结样本只支持 Nature Portfolio 内部 family，不能伪装成
   Nature、Science、Cell、PNAS 的跨出版社比较。
4. Fig.9 锁定案例发表于 2023 年，超出 1980–2017 冻结评分队列；
   图中只展示队列参照轮廓，并明确标为 `CASE NOT SCORED`。
5. Fig.10 的 400 行自动结果来自不同生成路径，只能用于诊断；
   同路径真实消融和 750 条盲法人类偏好完成前，不得声称模块因果贡献。
