# Experiments / outputs cleanup audit

## Decision

The repository now has one canonical figure namespace:

- code: `experiments/fig01` through `experiments/fig10`;
- results: `outputs/fig01` through `outputs/fig10`;
- historical implementation/result: `old`;
- current implementation/result: `new`;
- cross-figure shared code/result: `experiments/common` and `outputs/common`.

The current large shared implementation is
`experiments/common/new/base`. The current per-figure runners are deliberately
thin and reuse the frozen registry, model/OOF artifacts, shared builders and
exact recomputation cache. Fig.08 has no current numerical runner; its current
directory contains only the AI-illustration handoff boundary.

## What was removed

Only mechanically reproducible caches were deleted:

- `__pycache__`, `*.pyc`, and `*.pyo`;
- `.pytest_cache`, `.mypy_cache`, and `.ruff_cache`;
- empty migration source directories.

The initial cleanup reclaimed 18,111,270 bytes (17.27 MiB) of pre-existing
disposable caches. Tests and compilation temporarily regenerated bytecode; the
final cleanup removed it again, so the delivered tree contains no listed cache
directory. No paper data, reference edge, OpenAlex snapshot, derived
scientific table, OOF prediction, model result, human-label package, figure,
prompt asset, negative result, or provenance manifest was deleted.

During verification, the archived organizer's dry-run exposed that it still
copied a full duplicate package. That behavior was fixed to be genuinely
read-only, and the just-created 135 MiB duplicate was sent to the system trash;
it was not a pre-existing experiment artifact and remains recoverable there.

The first redesign result named `baseline_suite_r1` looks old by version
number, but it is an active frozen input. Deleting it would break current
figures.

## Optional future storage reduction

If an immutable external archive with checksum verification is created, the
largest local archival candidates are v6.1 R4, v6, and v6.1 R2–R3. This would
save roughly 275 MiB. This is an archival decision, not a routine cleanup:
remove them only after the archive is verified and the manuscript no longer
needs local exact reproduction.

About 14.9 MiB of current per-figure exports are byte-identical to shared-suite
exports. They were not replaced with hard links or symlinks because a later
rerun could mutate both paths through a shared inode. Independent exports are
safer and the saving is small.

## Verification

- the shared base suite was rebuilt in its canonical output directory;
- the nine code-backed thin runners (Fig.01–07, Fig.09, Fig.10) completed with
  zero audit-check failures;
- the nine thin-runner contract tests passed;
- the 12 current v6.1 figure/model tests passed;
- the migrated legacy figure/audit test batch passed after path fixes, and the
  one remaining case was individually re-run successfully;
- seven pytest-style tests for moved auxiliary scripts passed;
- active current code/configuration contains no pre-migration experiment or
  output root.

Fig.04 remains `DRAFT_HUMAN_LABELS`; Fig.09 remains
`BLOCKED_MISSING_MODEL_USING_HASHED_PRIOR_OUTPUT`; Fig.10 remains
`BLOCKED_COMPARABILITY`. Directory cleanup did not weaken these scientific
claim boundaries.
