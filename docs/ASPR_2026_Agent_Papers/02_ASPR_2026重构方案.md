# ASPR 2026 重构方案：从 Multi-Agent Reviewer Committee 到 Evidence-State Scientific Reviewer

## 0. 先给结论

如果允许大胆修改，我不会在当前 `Claim Decomposer / Evidence Mapper / Graph Analyst / Skeptic / Meta Reviewer` 五个 Agent 上继续加 Agent。

我建议把 ASPR 重构成一个新的系统范式：

# ASPR-ESR
## Evidence-State Scientific Reviewer
## 证据状态驱动的科学同行评审系统

它不把“Agent 角色”作为最基本单位，而把：

> **Review State（评审状态） + Evidence Controller（证据控制器） + Review Primitives（评审原语）**

作为最基本架构。

核心目标仍然完全不变：

> 输入论文 → 输出完整同行评审；创新判断有先行研究和图谱证据；方法学评论有论文内部证据；结论不过度声称；主要判断可以回溯。

---

# 1. 为什么我建议放弃固定五 Agent 委员会

当前结构：

```text
Claim Decomposer
        ↓
Evidence Mapper
        ↓
Graph Analyst
        ↓
Skeptic Reviewer
        ↓
Meta Reviewer
        ↓
Reflective Search
```

最大的问题并不是效果一定差，而是：

### 1.1 角色与任务重复

Graph Analyst、Skeptic、Meta 很多时候都在重复解释同一份 evidence。

### 1.2 信息通过自然语言层层转述

A 的输出成为 B 的 prompt，B 再总结给 C，很容易出现证据细节损失。

### 1.3 固定流程不符合真实评审

普通 claim 并不需要 Skeptic + Meta + 多轮反思；而 `first-ever` claim 可能反而需要更多检索。

### 1.4 Reflective Search 优化的是“草稿”，不是“证据状态”

语言越来越好，不代表证据越来越充分。

### 1.5 系统创新点容易被理解成常见 Multi-Agent 拼装

2026 年已经有大量 topology、routing、review agents 工作。ASPR 真正独特的是：

- novelty prior-art grounding；
- pre-publication graph calibration；
- ASPR-Qwen reviewer-style critique；
- traceable evidence-linked review。

应该把论文叙事聚焦到这些核心资产。

# 3. 第一核心：Paper Compiler

Paper Compiler 做一次结构化解析，输出 `PaperSpec`。

```yaml
PaperSpec:
  identity:
    title:
    doi:
    year:
    field:

  research_problem:
  method_summary:
  experimental_design:
  main_results:

  claimed_contributions:
    - claim_id: C1
      text:
      claim_type: method
      strength: first
    - claim_id: C2
      text:
      claim_type: empirical
      strength: normal

  sections:
    method:
    experiment:
    limitation:
```

同时生成 `Paper-specific Rubric`：

```yaml
ReviewRubric:
  novelty:
    - nearest_prior_work_identified
    - contribution_difference_explicit
    - strong_claim_checked

  methodology:
    - assumptions_supported
    - method_description_complete

  experiments:
    - baselines_adequate
    - ablation_sufficient
    - statistics_appropriate

  reproducibility:
    - data_available
    - code_or_pseudocode
    - hyperparameters
```

来源思想：ReviewGrounder + ResearchRubrics。

# 4. 第二核心：Review State，而不是 Agent 对话历史

Review State 是系统最重要的数据结构。

它取代：

- 多 Agent 长对话；
- Claim Card 的孤立列表；
- Reflective Search 的大量 draft history。

建议结构：

```yaml
ReviewState:
  paper_spec: ...
  rubric: ...

  novelty_claims:
    C1:
      claim_text:
      strength:
      prior_art:
        - paper_id:
          relation:
          evidence_span:
          temporal_valid: true
          confidence:
      nearest_prior_work:
      novelty_difference:
      graph_packet:
      graph_applicability:
      counterfactual_search_done: false
      evidence_coverage:
      evidence_conflict:
      novelty_judgment:
      evidence_sensitivity:
      confidence:

  internal_review:
    strengths: []
    major_weaknesses: []
    minor_weaknesses: []
    methodological_issues: []
    experimental_issues: []
    reproducibility_issues: []

  unresolved_questions: []
  controller_history: []
  verifier_status: ...
```

所有模块只能：

`Read Current State → Add/Update Specific Fields`

而不能随意覆盖别人已有证据。

来源思想：IterResearch + MEM1。

# 5. 第三核心：Evidence Controller——系统里唯一需要强调的 Agent

Controller 不负责写评审，也不负责专业判断。

它只做：

> **根据当前 Review State 决定下一步最值得执行的动作。**

## 5.1 动作空间

```text
EXTRACT_MORE
SEARCH_PRIOR_ART
RELATION_CHECK
COUNTERFACTUAL_SEARCH
GRAPH_CALIBRATE
RUN_QWEN_REVIEW
ASK_SPECIALIST
EVIDENCE_STABILITY_TEST
VERIFY
FINALIZE
```

## 5.2 简化后的决策规则

第一版完全不需要 RL。

```python
if not qwen_review_done:
    RUN_QWEN_REVIEW

if claim.prior_art_coverage < threshold:
    SEARCH_PRIOR_ART

if claim.strength in {"first", "breakthrough", "unprecedented"}:
    if not counterfactual_search_done:
        COUNTERFACTUAL_SEARCH

if prior_papers_conflict:
    RELATION_CHECK

if complex_statistical_issue and confidence < threshold:
    ASK_SPECIALIST("statistics")

if evidence_complete:
    EVIDENCE_STABILITY_TEST

if all_required_rubrics_resolved:
    VERIFY
```

真正需要 LLM Controller 的情况，只放在规则无法决定的模糊状态。

来源思想：Eigen-Agent + SupervisorAgent + CARD。

# 6. 外部证据分支：从 Similarity Retrieval 升级为 Prior-Art Reasoning Engine

当前优势保留：

- Semantic Scholar / OpenAlex；
- BGE-M3 recall；
- OpenScholar reranker。

但搜索不再结束在 Top-k papers。

## 6.1 第一轮：Normal Prior-Art Search

```text
Claim
↓
Query Generation
↓
BGE-M3 Recall
↓
Reranker
↓
Top candidates
↓
Claim–Paper Structured Comparison
```

## 6.2 第二层：Relation Classification

每个候选文献产生：

```yaml
relation:
  type: PARTIAL_PRECEDENT
  target_claim_span: ...
  prior_paper_span: ...
  commonality: ...
  difference: ...
  confidence: 0.82
```

推荐关系集：

```text
ANTECEDENT
PARTIAL_PRECEDENT
EXTENSION_BASE
SUPPORTING
CONFLICTING
PARALLEL
DISTANT
```

来源思想：SciNet。

## 6.3 第二轮：Counterfactual Prior-Art Search

只在必要时触发。

示例：

作者：

> “We introduce the first NeuroGraph-X framework for ...”

正常查询可能被作者自造词 `NeuroGraph-X` 主导。

反事实查询自动变成：

```text
核心任务 + 核心机制 + 应用领域
- 删除方法品牌名称
- 添加旧术语同义词
- publication_year < target_year
```

然后从最接近候选论文反向追 citation graph。

来源思想：CF-RAG + Failure is Feedback。

# 7. Graph 分支：保留，但从“Agent”降级为 Evidence Tool

这是 ASPR 最独特的部分之一，因此必须保留。

但 Graph Analyst 不需要是自由生成 Agent。

输入：

```yaml
ScorePacket:
  score_mechanism:
    boundary_perturbation:
    community_diffusion:
    interdisciplinarity:
    recombination:
    brokerage:
  performance_calibrated:
  percentile:
  quality_flags:
  confidence:
  limitations:
```

Graph Interpreter 使用固定规则生成：

```yaml
graph_evidence:
  applicable_to_claim: true/false
  supportive_channels: []
  limiting_channels: []
  allowed_interpretation:
  prohibited_interpretation:
```

强制规则：

1. Prior-art direct evidence > graph prior。
2. Graph 只能调整创新判断强弱，不能创造 contribution。
3. Graph 不适用于某 claim 时显式标记 `not_applicable`。
4. Graph unavailable ≠ low novelty。

这样更可复现。

# 8. ASPR-Qwen：保留，但改变职责

ASPR-Qwen 不再“直接写一份完整最终 review”。

它变成 Internal Evidence Critic：

```yaml
internal_review:
  strengths:
    - statement:
      paper_evidence:
      confidence:

  weaknesses:
    - statement:
      paper_evidence:
      severity:
      actionable_suggestion:

  methodology:
  experiments:
  reproducibility:
  limitations:
```

关键要求：

> 每个 major criticism 必须提供论文内部定位证据。

这样 Graph/prior-art 是 external evidence；ASPR-Qwen 是 internal evidence，两条线非常对称。

# 9. Selective Expert Escalation：不要固定 Reviewer Committee

维护一个 Expert Pool：

```text
Novelty Specialist
Statistics Specialist
Methodology Specialist
Citation Specialist
Domain Specialist（可选）
```

只有 Controller 判断必要时调用。

例如：

```text
first-ever + prior-art conflict
→ Novelty Specialist

复杂统计显著性/生存分析/因果推断
→ Statistics Specialist

citation context 与摘要结论不一致
→ Citation Specialist
```

来源思想：Graph-of-Agents + CARD + GraphPlanner + HieraMAS。

如果高风险，可以对一个功能节点使用“双模型 propose → synthesis”，但只限关键 claim。

# 10. Process Confidence：取消纯主观 uncertainty

当前的：

`uncertainty = medium`

太依赖 LLM 自报。

建议将 claim confidence 分解：

```text
C_retrieval      检索覆盖
C_relation       prior-art 关系判定一致性
C_temporal       时间边界可靠性
C_graph          graph packet 置信度
C_internal       论文内部证据充分度
C_stability      证据扰动后判断稳定性
C_verifier       verifier 检查
```

第一版甚至可以手工加权：

```text
Confidence = weighted_sum(...)
```

后续有人工标注数据以后，再训练 calibration model。

来源思想：Agentic Confidence Calibration。

---

# 11. Evidence Stability Test：我最推荐新增的科学机制之一

对于最终关键 judgment，做轻量扰动：

### Test A

去掉 graph prior，再判断 novelty。

### Test B

去掉最相关 prior paper，再判断。

### Test C

只保留 top-3 prior papers，再判断。

### Test D

替换一次 query formulation，再检索并判断。

记录：

```yaml
stability:
  original: high
  without_graph: medium
  without_top1_prior: high
  alternate_query: medium
  stability_score: 0.72
```

如果结论非常敏感：

> 不一定说结论错，但应该降低语言强度。

来源思想：Epistemic Calibration。

# 12. Review Compiler：最终文本只允许从 Review State 生成

Composer 不重新阅读所有搜索 history。

输入只有：

- PaperSpec；
- resolved Review State；
- paper-specific rubric；
- citation table。

输出：

1. Overall assessment；
2. Novelty & significance；
3. Strengths；
4. Major weaknesses；
5. Methodology & experiments；
6. Prior-art comparison；
7. Evidence adequacy；
8. Limitations & uncertainty；
9. Actionable revisions；
10. Overall recommendation。

规则：

> Composer 只能表达 State 中已有判断，不允许创造新的 prior-art fact 或新 criticism。

---

# 13. Verifier：像代码 lint，而不是再请一个 Meta Reviewer

Verifier 只检查硬约束：

```text
[ ] 每个主要 novelty judgment 是否绑定 prior-art evidence
[ ] 引用是否真实存在
[ ] 引用内容是否支持对应句子
[ ] first/breakthrough 是否做过 counterfactual search
[ ] graph signal 是否被误当 quality proof
[ ] major criticism 是否能定位 paper evidence
[ ] overall recommendation 是否与前面 major issues 一致
[ ] uncertainty/confidence 是否遗漏
[ ] temporal cutoff 是否满足
[ ] Composer 是否创造 Review State 之外的新事实
```

Fail 时只做一次 targeted repair，不再 Beam Search 多轮重写。

# 14. 原系统模块怎么处理

| 当前模块 | 新系统处理 |
|---|---|
| Claim Decomposer | 合并进 Paper Compiler 的 claim extraction |
| Evidence Mapper | 升级为 Prior-Art Reasoning Engine |
| Graph Analyst | 删除独立 Agent，改成 deterministic Graph Interpreter |
| Skeptic Reviewer | 删除固定角色，功能由 Counterfactual Search + Stability Test 取代 |
| Meta Reviewer | 删除，功能拆给 Controller + Verifier + Process Confidence |
| Reflective Search | 删除主路径，改为 Targeted Repair |
| ASPR-Qwen | 保留并强化，作为 Internal Evidence Critic |
| ScorePacket / 图指标 | 保留，作为外部结构校准工具 |
| Claim Cards | 扩展并并入统一 Review State |

# 15. 最终最推荐的技术创新点

如果 ASPR 本身要写方法论文，我会把贡献集中成四点，而不是“设计了若干 Agent”。

## Contribution 1 — Evidence-State Review Architecture

以结构化 Review State 作为所有评审推理的共享状态，避免多 Agent 自然语言级联误差。

## Contribution 2 — Relation-aware + Counterfactual Prior-Art Reasoning

不仅找语义相似论文，还识别 antecedent/extension/conflict 等关系；对强创新主张执行反事实检索。

## Contribution 3 — Pre-publication Graph-Calibrated Novelty

继续保留 ASPR 最独特的知识图谱结构性创新先验，并严格限制其解释边界。

## Contribution 4 — Evidence-Supervised Agentic Control and Calibration

Controller 根据证据缺口决定是否继续搜索/调用专家，并通过 process confidence + evidence stability 调节最终表述强度。

这四项比“五 Agent 委员会”更像 2026 年的 Agent 思路，也更容易解释和消融。

# 16. 推荐实施优先级

## Phase 1：最小可行重构

1. 建立 Review State schema；
2. Claim mapping 改成结构化 LLM comparison；
3. ASPR-Qwen 改结构化 internal evidence 输出；
4. 删除 Reflective Search，改 Composer + Verifier。

## Phase 2：真正增加 2026 Agent 新机制

5. Evidence-Gap Monitor；
6. Counterfactual Prior-Art Search；
7. Relation-aware prior-art labels；
8. Evidence Stability Test；
9. Process Confidence。

## Phase 3：可选增强

10. Selective Expert Escalation；
11. Search Strategy Memory；
12. 双模型 high-risk claim verification。

## Phase 4：论文完成后再考虑

13. MASS 类离线 prompt/routing 自动优化；
14. GraphPlanner/CARD 类学习式 routing；
15. RL Controller。

# 17. 最终一句话定义

> **ASPR-ESR is an evidence-state scientific reviewer that maintains a structured review state, adaptively acquires and challenges external evidence, combines pre-publication graph calibration with internally grounded critique, and compiles the resolved state into a traceable peer-review report.**

直白中文：

> **ASPR 不再是一群 Reviewer Agent 互相讨论，而是一个持续维护“当前证据状态”的科学评审智能体：它知道现在掌握了什么、还缺什么、什么时候应该继续查文献、什么时候应该质疑强创新主张、什么时候需要专家，以及什么时候证据已经足够生成最终评审。**
