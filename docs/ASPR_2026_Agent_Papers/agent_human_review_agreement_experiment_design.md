当前可运行实验固定为三篇 Nature Communications 论文：

- `10.1038/s41467-023-36025-x`，检索截止日为 2021-07-14；
- `10.1038/s41467-023-43541-3`，检索截止日为 2023-03-14；
- `10.1038/s41467-024-51536-x`，检索截止日为 2024-03-09。

这是一项 revision-aware audit：Agent 阅读终稿，但先前工作检索严格截至原投稿日；真人参考只保留终稿中仍存在或部分解决的问题，已解决问题单列用于检测“问题复活”。所有 AI 审稿和单次盲匹配裁判均固定为 `gpt-5.6-terra`、中等推理强度。

## 报告范围

结果只报告真实、可回溯的观察值：运行可用性、严格和软原子点评匹配、修订状态分层召回、已解决问题复活、独立的新颖性理由与外部证据检查、论文专属八维 rubric，以及错误论文配对负对照。

双方为空或没有目标点评的指标记为 `not_estimable`，不记作满分。严格匹配只统计同一命题且同向的点评；部分匹配作为独立软指标；矛盾关系单列。AI 和真人的证据键分别在各自 EvidenceStore/重建包中校验。

三篇样本只用于工程和协议验证：不报告显著性、总体泛化、真人等价或人类水平结论。裁判为单模型单次运行，结果还必须附带该限制。

## 运行

```bash
python3 scripts/run_gear_revision_audit.py all
```

产物默认写入 `outputs/gear/revision_audit/nature_pilot3/`，包括输入哈希、AI 运行健康检查、盲裁判包与响应、rubric、逐篇审计、负对照、指标和最终报告。
