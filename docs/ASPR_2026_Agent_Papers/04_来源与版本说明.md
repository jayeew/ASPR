# 论文全文来源与版本说明

## 说明

本包只收录公开可合法获取的全文。优先顺序：

1. 正式会议 proceedings PDF；
2. ACL Anthology / PMLR 等正式公开版本；
3. OpenReview 已录用公开版本；
4. 如果 OpenReview PDF 下载触发浏览器验证，则使用作者公开的 arXiv 版本，并明确标注 `AuthorVersion`。

**注意：有些论文的 arXiv 编号以 `2510` / `2511` 开头，是因为作者在 2025 年先公开了预印本，但它们的正式会议归属是 ICLR 2026。这里按“2026 正式会议论文”纳入，而不是把预印本年份误当成会议年份。**
