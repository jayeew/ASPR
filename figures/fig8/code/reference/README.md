# Fig8｜期刊层面的局部知识结构与全球科研参与

正式版使用 2023–2025 年三个领域的 419,081 篇论文和 6,985 种期刊。a 为 Nature 主刊局部图变化与案例；b 为期刊×领域比较和四刊的逐篇分布；c 为国家与机构参与。各面板的有效分母、计数规则和小样本处理见[完整图注](../../outputs/fig8_reference/caption_en.txt)。

从项目根目录运行 `python -m figure_pipeline.fig8_reference --render-only`。`build.load_data` 从 `outputs/fig8_data/analysis/tables/` 读取逐篇和聚合表，其中包括期刊、引用和机构影响指标。使用[正式 Fig8](../../outputs/fig1-11_final/Fig8/) 核对排版。
