# Fig. 2 汇报版 README

## 一句话结论

Fig. 2 的作用是解释：我们为什么把论文发表当天就能看到的参考文献结构，压缩成七个可计算指标，并用它们刻画一篇论文对知识图谱的潜在扰动能力。

可以向领导这样概括：

```text
Fig. 1 展示 landmark paper 发表后会改变知识图谱；
Fig. 2 进一步说明，这种改变在论文发表当天已经能从参考文献结构中看到一些早期信号。
```

## 这张图想回答什么

Fig. 2 不是在预测引用量，也不是在给论文打最终影响力分。它回答的是：

```text
如果只看一篇论文发表当天的参考文献和发表前的知识图谱，
我们能不能找到一组有机制解释、彼此不重复、并且和未来图谱变化有关的指标？
```

最终保留七个指标：

| 指标 | 汇报时怎么解释 |
|---|---|
| `B` | 论文是否把原本分开的知识群体连接起来 |
| `RS` | 参考文献是否覆盖足够宽、足够远的知识来源 |
| `DeltaQ0` | 论文加入后是否立刻扰动原有社区边界 |
| `Uzzi` | 参考文献组合是否包含不常见但可解释的新组合 |
| `RTD` | 参考文献是否指向多个不同知识社区 |
| `BurtIP` | 论文是否处在结构洞位置，连接低冗余知识 |
| `PDE` | 论文的参考基础是否具有未来扩散到多领域的潜力 |

## 使用了什么数据

数据主要来自 Fig. 1 已构建的本地知识图谱和 OpenAlex 缓存。

当前 strong-mode 版本使用四个研究领域：

```text
CRISPR
graphene / 2D materials
iPSC reprogramming
transformer / foundation models
```

关键点：

- 计算七个指标时，只使用论文发表当天可见的信息。
- 未来数据只用于验证这些指标是否真的对应后续知识图谱变化。
- Panel a 使用 CRISPR 作为直观示例，方便展示 `发表前 -> 发表当天 -> 未来` 的图谱变化。

当前输出更适合作为“诊断性实证结果”，还不建议表述为强因果证明。原因是部分领域样本量和参考文献覆盖还不够充分，matched controls 也有较多放宽匹配的情况。

汇报提示：

- “诊断性实证结果”表示方法链条已经跑通，也看到了一定信号，但还不适合包装成最终强结论。
- `matched controls` 可以翻译成“匹配对照组”：不是拿一篇论文和所有论文乱比，而是找同领域、近年份、参考文献数量相近的普通论文作为公平参照。

## 每个 Panel 怎么讲

### Panel a: 发表当天的测量场景

这一 panel 讲时间顺序。

汇报话术：

```text
我们把一篇焦点论文放进知识图谱里看：
发表前是 G−，发表当天加入论文和它的参考文献边得到 G0，
未来若干年后得到 G+τ。
七个指标只在 G0 计算，不偷看未来。
```

怎么看：

- 左图是论文发表前的知识图谱。
- 中图是论文发表当天，红色星号代表焦点论文。
- 右图是未来窗口后的图谱变化。
- 这说明我们的指标是“发表当天信号”，不是事后影响力指标。

图中元素怎么解释：

- 三个大框分别是三个时间点：`G−`、`G0`、`G+τ`。
- 大框之间的箭头表示时间推进，不表示模型训练流程。
- 彩色圆圈表示知识社区或主题群，圆圈越大，说明该社区里论文越多。
- 圆圈里的小点是该社区中的论文示意点，不需要逐个解释。
- 灰色连线表示当时图谱里已经存在的引用或知识连接，线越粗通常表示连接越多。
- 中图和右图里的红色星号是焦点论文 `p`。
- 从红色星号发出的虚线表示焦点论文发表当天连接到的参考文献社区。
- 每个大框角落里的 `n=` 表示该时间快照中纳入的论文数量。

讲这一 panel 时重点强调：红色星号只在中图开始出现，说明我们是在论文发表当天计算指标，而不是用未来结果反推。

### Panel b: 为什么从 92 个候选指标筛到 7 个

这一 panel 讲指标选择的合理性。

汇报话术：

```text
我们不是主观挑了七个指标，而是从 92 个候选指标出发，
逐步排除会泄漏未来信息、依赖作者/期刊声望、或与图谱扰动机制无关的指标。
最后保留七个最可解释、最贴近图谱机制、且相互不完全重复的指标。
```

怎么看：

- `92` 是候选指标库。
- 逐步筛掉未来引用量、期刊声望、作者声望、文本/LLM 评分等不适合作为发表日参考文献指标的变量。
- `7` 是最终用于 Fig. 2 和 Fig. 3 的指标基。

图中元素怎么解释：

- 上方一串方框是筛选漏斗，每个方框里的数字是该步骤后剩下的指标数量。
- 方框之间的箭头表示逐步筛选，不是模型计算过程。
- 每个方框下面的文字说明筛选条件，例如“不能泄漏未来”“必须 reference-only”“必须和图谱扰动机制相关”。
- 中间表格左侧是筛选步骤，中间是保留标准，右侧是被排除的指标例子。
- 底部彩色标签是最终七个指标，每个颜色只用于区分指标类别，不表示好坏或权重大小。

讲这一 panel 时可以说：这张图的目的不是展示结果高低，而是交代“七个指标从哪里来，为什么不是随便选的”。

### Panel c: 七个指标覆盖哪些机制

这一 panel 讲七个指标不是同一种信号。

汇报话术：

```text
这七个指标分别覆盖知识扩展、桥接、边界扰动和非典型组合等机制。
所以它们共同构成一个机制画像，而不是单一中心性或单一多样性指标。
```

怎么看：

- `Breadth` 表示知识来源是否宽。
- `Brokerage` 表示是否连接不同知识社区。
- `Boundary` 表示是否扰动社区边界。
- `Atypicality` 表示是否有非典型知识组合。

这个 panel 的核心信息是：七个指标各有机制位置。

图中元素怎么解释：

- 每一行是一个核心指标。
- 每一列是一类机制证据。
- 实心圆表示这个指标主要支持该机制。
- 空心圆表示这个指标也和该机制有关，但不是最主要解释。
- 左侧指标名称的颜色和全图其他 panel 保持一致，方便追踪同一个指标。
- 这个 panel 没有数值大小，属于机制解释图。

讲这一 panel 时可以说：七个指标不是七个同类变量，而是覆盖四类机制证据的“指标组合”。

### Panel d: 七个指标是否重复

这一 panel 讲非冗余性。

汇报话术：

```text
我们把候选指标两两比较，检查它们是不是都在测同一件事。
结果显示，最终七个指标分布在不同相关簇中，
因此保留它们是为了覆盖不同机制，而不是重复堆指标。
```

怎么看：

- 热图颜色越深，说明两个指标越相关。
- 如果七个核心指标都挤在同一个区域，说明冗余严重。
- 当前图的重点是展示：七个指标覆盖了不同候选指标家族。

图中元素怎么解释：

- 横轴和纵轴都是候选指标。
- 每个格子表示两个指标之间的相关性。
- 红色表示两个指标倾向于一起升高，蓝色表示一个高时另一个倾向于低。
- 颜色越接近白色，说明两者关系越弱。
- 旁边的色条是相关系数范围，用来解释颜色深浅。
- 被加粗或染色的坐标标签是最终保留的七个核心指标。
- 右侧的小图例把候选指标分成几组，例如桥接、多样性、结构洞、边界扰动等。

讲这一 panel 时重点说：我们希望核心指标分布在不同相关簇中，这样才说明它们提供的是互补信息。

### Panel e: Landmark 和未来强扰动论文是否更高

这一 panel 讲指标是否能区分重要案例。

汇报话术：

```text
我们把 landmark paper 和未来图谱扰动较强的论文，
与同领域、近年份、参考文献数量相近的普通论文比较。
如果这些论文在七个指标上更靠前，说明指标确实抓到了一些早期结构信号。
```

怎么看：

- 横轴是相对 matched controls 的百分位。
- 越靠右，说明该论文在这个指标上越高。
- 星号表示 landmark 论文的中位水平。
- 灰点表示未来强扰动论文。

如果多个指标都靠右，可以说这些指标对 landmark / 高扰动论文有区分力。

图中元素怎么解释：

- 每一行对应一个核心指标。
- 横轴从 0 到 100，是在匹配对照组里的百分位排名。
- 50 附近表示和普通对照差不多；越接近 100，说明越明显高于对照组。
- 空心圆表示 landmark paper 在该指标上的位置。
- 灰色小点表示未来图谱扰动较强的论文在该指标上的位置。
- 彩色星号是 landmark paper 的中位数，方便看总体位置。
- 右侧数字是 landmark 中位百分位，便于口头汇报。
- 底部说明会提示对照组匹配情况，例如对照数量和是否用了放宽匹配。

讲这一 panel 时可以说：如果 landmark 和未来强扰动论文集中靠右，说明这个指标确实在重要案例上更突出。

这里的 `matched controls` 讲解口径：

```text
为了公平比较，我们给每篇焦点论文找一组背景相似的普通论文。
如果焦点论文在这些对照组里排到很靠前，
说明它的发表日结构信号确实比较突出。
```

### Panel f: 发表日指标是否对应未来图谱变化

这一 panel 是 Fig. 2 最重要的实证验证。

汇报话术：

```text
最后我们检查七个发表日指标，是否和未来真实发生的图谱变化一致。
红色越强，说明发表日指标越能对应未来图谱扰动。
带加号的格子表示这个正相关在 bootstrap 检验下更稳定。
```

怎么看：

- 行是七个发表日指标。
- 列是未来图谱变化，例如跨社区扩散、领域熵增加、边界混合、路径缩短等。
- 红色表示正向对应。
- `+` 表示这个对应关系更稳。

注意：这不是最终预测模型，而是验证七个指标是否有真实未来图谱含义。

图中元素怎么解释：

- 每一行是一个发表日指标。
- 每一列是一种未来图谱变化结果。
- 每个格子里的数字是相关性，表示该指标和未来变化的排序关系。
- 红色格子表示正相关，指标越高，未来变化通常也越强。
- 蓝色格子表示负相关，指标越高，未来变化反而通常更弱。
- 颜色越深，相关性越强。
- 格子里的 `+` 表示 bootstrap 检验后仍然比较稳定。
- 列名中的 `*` 表示这个未来结果和某个发表日指标定义上比较接近，适合作为内部一致性检查，不应当当成完全独立验证。
- 底部色条帮助解释颜色和相关性大小的对应关系。

讲这一 panel 时重点说：这张图回答的是“发表日指标有没有未来图谱含义”，而不是“最终模型准确率有多高”。

这里的 `bootstrap` 讲解口径：

```text
bootstrap 就是重复抽样检验稳定性。
如果反复抽样后这个正相关仍然存在，
我们就更有信心说它不是一次偶然结果。
```

## 当前结果该怎么表述

建议汇报表述：

```text
目前 Fig. 2 已经形成了完整的指标筛选和验证链条：
七个指标具有清晰机制解释，彼此不完全冗余，
并且在多领域数据中与若干未来图谱扰动结果呈现正向对应。
```

同时建议加一句边界：

```text
当前版本更适合作为诊断性实证结果；
要升级为强证据，还需要扩大样本、提高参考文献闭包覆盖率，并减少 controls 的放宽匹配比例。
```

这里的“参考文献闭包覆盖率”可以解释为：

```text
一篇论文引用了很多文献，如果我们的本地图谱只收录了一小部分，
那对它知识来源的判断就不完整。
覆盖率越高，图谱分析越可靠。
```

## 和 Fig. 3 的关系

Fig. 2 解决“为什么是这七个指标”。

Fig. 3 解决“这七个指标应该怎么加权，以及加权后的分数能不能 out-of-fold 预测未来图谱扰动”。

`out-of-fold` 可以翻译成“没参与训练的数据上的验证”。也就是先用一部分论文学习权重，再拿模型没见过的论文测试，避免自我验证。

汇报时可以这样衔接：

```text
Fig. 2 建立指标体系；
Fig. 3 在这个指标体系上学习权重并做严格验证。
```
