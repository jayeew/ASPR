# Fig.9 — Locked 2023 TLR3 end-to-end case

**Question.** What does each ASPR module contribute for one real, preselected
Nature Communications paper, and can every final claim be traced to evidence?

**Case.** The previously locked 2023 TLR3 paper, its local manuscript,
transparent review, and hash-verifiable stored system outputs.

**Panels.** Input/time boundary; graph-evidence and ASPR-Qwen swimlanes;
five-angle measurement availability; complementary agent/Qwen outputs;
claim–evidence–verifier network; and concern overlap with human review.

**Boundary.** The case is outside the 1980–2017 OOF cohort and is not currently
feature-ready in the frozen OpenAlex view. No eight-indicator fingerprint is
imputed. If the original checkpoint is unavailable, stored outputs are shown
as prior artifacts rather than a current rerun.
