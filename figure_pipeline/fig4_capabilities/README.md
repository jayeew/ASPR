# Fig4 原五篇能力试跑

仅原5篇×7配置：35次直接报告生成、35次统一评价，上限70次新增任务启动。
复用上一轮论文、GEAR、结构化图材料、原文及核心参考；七配置的字段删除不变。
旧 Fig3 清单仅提供评价主题，原文和原生图事实用于核验。所有新结果写入独立目录。
路径标签按已确认的删除要求直接去掉，修正旧代码将删除标签替换为 semantic_only 的问题。

评价分别记录科学增量解释、知识关系刻画、联合贡献解释、结构刻画和引用联系辨别，
同时保存原有两条核心贡献的评价。不合成总分，不要求完整系统排名第一。
同篇七配置采用共同适用性：无正向路径记录的论文不进入正向引用联系效果比较，
快照中的零记录不能证明全局没有引用关系。此试跑评价共同 writer 下的报告输入效应。

```bash
python -m figure_pipeline.fig4_capabilities prepare
python -m figure_pipeline.fig4_capabilities run
python -m figure_pipeline.fig4_capabilities status
python -m figure_pipeline.fig4_capabilities aggregate
```

所有调用使用 gpt-5.6-luna，生成 high、评价 xhigh；沿用 HTTP 客户端和调度，
并发上限64，原35个报告对象最多35个同时在途。每对象先生成再评价。
关闭自动重试和模型格式修复；完整响应可本地恢复，失败/局部漏评公开保留。
没有其余95篇入口，不包含信息聚类、融合追踪、风险评价或绘图。
工程核对只读代码逻辑和实际试跑产物，不编写或运行回归测试。

主比较的四条件使用逐维度共同完整论文，组件差值使用相应两个条件的完整配对。
原始模型评分与报告原句中的科学口径争议另存人工阅读记录，不改写模型响应或补调用。
