# 缺失实验的预声明协议 v1（待执行，不是研究结果）

主队列固定为原 200 篇，ID 来自 FROM_WEB/data/comparison_cohort.json；1000 篇扩展另设 cohort，不回填为同一运行。当前修订依据 2026-09-09 保存快照，不能代表后续运行最新进度。

## 统一运行与版本

每个运行保存 cohort_id、snapshot_id、run_id、代码版本、模型与角色路由、原文/claims/历史文本并集的哈希、时间截点、检索预算、调用/输入输出 token 和费用记录。已有解释、joint 和缓存必须按变体重新生成；不复用包含被删除信息的解释。保留失败及中断尝试。

执行状态允许 not_run、running、failed、completed_no_usable_evidence、completed_with_usable_evidence、not_applicable；没有调度/尝试证据时状态为 null 并写 missing_reason，不能仅根据文件不存在断言 not_run。证据状态、判断强度、独立核验结论分别保存。

## Fig3 / Fig5 / Fig7 共用独立审查集

抽样单位为论文，分层字段为期刊、发表日期、来源领域及 GEAR 执行状态；保存每层总体和抽样概率。先建立盲化试标集以检查标签可操作性及标注者一致性，再按希望估计的置信区间精度决定样本量；此处不预设每 panel 相同 n，也不事后挑选支持系统的案例。

关系允许多标签：复用/扩展/重组/新条件成立/不支持/无法判定，逐条区分存在、不存在、无法判。标注者只读目标原文与冻结历史原文，不看结构指标、系统身份和系统判词；独立双人标注后对分歧仲裁。记录逐条 source span、判断理由和边界。人工标注与模型评估分别保存，不将模型复评写为人工核验。

Fig5 以同 claim、同 scope、同历史对照对象的判断为观察单位，分支到 Full 的主要变化互斥编码为有效补充、有效纠正、有害改变、无实质改变、混合、无法判。新增文字本身不算收益；论文聚类区间。同一原文审查集衡量 Fig7 的证据充分性与判断强度是否相配，而不是用运行完成率当正确率。

## Fig4 身份移除后重评

使用 evaluations/identity_blind_v2 输出，保留原 human_evaluation。新 schema 不含 system，来源/段落标识使用局部中性别名；映射留在裁判外。报告正文仍可能透露方法特点，应披露残余可识别性。同一参考 ID 对齐旧/新评估，比较范围、立场、理由、矛盾与裁判误配；不能仅用重新调用模型获得“独立真实正确性”。

## Fig6 受控路径

先从同一层级事实、同一历史文本集合构造所有变体。每个变体运行同一 Graph 解释阶段、同一 joint 解释机会与同一整篇 writer；删除指标/路径后重新计算其依赖解释。GEAR 与 Graph 在融合前保持独立。source catalog 纳入暴露审计，不通过文本摘要泄漏删除字段。比较模型、推理阶段和资源预算均记录并审查。

Joint 对照拥有相同 claims、历史文本并集以及一次整篇综合机会，仅不提供显式 joint 结构。2×2 指标×路径实验需要四组完整配对结果，交互量为 (both − no_metrics) − (no_paths − neither)，按论文 bootstrap，不将损失相加。不满足统一路径时名称限定为 pipeline variant comparison，并阻止因果消融主图。

## Fig8 / Fig9

现有 Fig8 仅为历史标题短语基线；历史去重冻结后再读取 2025 标签。真正方向预测应以历史 claims 规范化成方法—对象—条件候选，文本/Graph/融合在同一候选集排序。未来独立论文采纳、组合延续和跨社区关系形成需预先定义与时间隔离；历史图不可用时不声称长期影响已验证。单一起点的 bootstrap 不能替代跨时间泛化。
