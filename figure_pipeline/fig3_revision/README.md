# Fig.3：100 篇论文的 GEAR、Graph、Full 修复

当前研究使用 `outputs/fig3_reference/dataset/papers.jsonl` 的 100 篇论文与原始审稿材料。所有生成式判断使用 `gpt-5.6-luna`。本次只重跑受影响的 GEAR、Graph、Full 分析与报告；Direct-A、EACL、ReviewGrounder 的既有分析和报告保留。共享贡献、目标论文原文、审稿原文和原生 Graph 邻域事实继续使用。共同历史参考与评价按修复后的对象、证据和分母重新计算。

原 719 条共享对象中，`s42004-026-01998-5::CLAIM::05` 和 `::CLAIM::06` 分别是作者分工与经费获取声明，已从科学贡献对象中移除；现有合法对象共 717 条。其余身份不变，该论文的联合图由保留贡献的既有邻域重新计算，原始提取与证据记录保留。

## 当前处理口径

- 核心贡献从论文原文句子中选择，再映射到既有共享贡献。模型返回句子 ID，由程序复制原句；不以论文摘要式笔记代替原文。
- 历史检索分别保留词法、语义和外部检索结果。依赖或限流失败不抹去成功渠道；恢复失败渠道后重新排序，保留成功下载的来源。历史 PDF 使用 PyMuPDF；外部检索按请求节流并尊重重试等待。
- 候选排序合并整篇论文视角与贡献检索词视角的名次，再截取最终来源；不再串接两个排序后取前十，导致第二个视角被全部截掉。
- 检索请求与全文准备分配独立工作位置，总网络并发不增加；避免新全文排在全体论文的检索请求之后。中断恢复复用原始全文记录，正在重算的来源清单不保留旧的最终结果供后续误用。
- OpenAlex 查询移除会被解释为通配符的问句标点；长时间限流不阻塞本地材料。OpenAlex 暂时不可用时采用 Crossref 后备检索，按公开接口要求串行请求，保留提供方、题录/摘要/全文及日期精度的边界；仅题录不能确立历史差异。
- Crossref 已返回无公开 PDF 链接且 OpenAlex 仍在限流等待时，不重复查询相同 Crossref DOI 元数据；保留可用摘要或题录，并明确未取得全文。
- 历史参考逐篇阅读相关先例，再综合判断。优先采用已有全文；需要时补检索一次。无法建立有原文支撑的相关比较，仍记为材料不足；目标论文自身不能单独确立历史差异。
- 独立先例排除同 DOI、同标题以及全文首页明确指向目标 DOI 的预印本正式发表版本关系；全文获取后再次应用该排除，避免改标题的自身预印本被当成历史覆盖。
- GEAR 与 Graph 在融合前独立判断。Full 按同一贡献 ID 对齐两分支，并逐项记录发现的保留、合并、修正、放弃或待核验理由。引用采用来源 ID 和原文位置，避免不同临时证据包的段落编号冲突。
- Graph 与 Full 写作保留完整的原生邻域观察；目标主张元数据不作为独立证据，省略该部分时保留其余文本在原始来源中的位置。报告和融合按贡献读取 GEAR 原先使用的每篇先例片段及同等论文材料，避免在融合输入处先丢失分支证据。
- 只有 Full 取消报告字数目标。GEAR、Graph 和既有基线保留约 1200—2000 中文字的目标，不硬截断。Full 的比较因此包含更宽松的报告长度条件，不能单凭结果归因为融合结构。
- 评价使用原报告；报告、断言、核心贡献和审稿问题身份不进入通用背景摘要。评价可使用 64,000 字符材料预算，分支、融合及报告任务可使用 96,000 字符以保留逐来源证据；普通背景阅读继续使用小材料预算，超大任务需拆分对象。
- 实质科学断言，包括具体范围限制，均需核验。Graph 的生成式 claim_text 不能作为论文事实的独立证据。支持、适用范围、原始可追踪性和创新判断分别记录。
- 审稿问题只来自真实 reviewer 段落；合法跨段引用保留，纯论文背景线索不进入真人问题分母。随访要求明确的同一审稿人、更晚轮次和原始引句；原文件 Version 0 对应首次审稿。作者回复和一般致谢不能证明解决；附件中独有的审稿意见仍保留，重复文本不重复计数。
- 信息聚类先对齐科学内容，再独立计算支持状态。Full 新增内容、使分支已有内容获得支持，以及提及但未获支持分别统计。错误传播逐个对齐实际分支错误对象，沉默不算明确纠错。
- 固定 20 篇同模型重复评价使用重新生成的当前对象；同时报告联合字段一致性与单字段一致性。构造控制只从首轮有支持、范围正确的实际原句中选择；引用错配只用被引用来源判断。

Full 优于单分支是待检验的研究目标，不是数据生成或选择条件。材料不足、技术失败和不可估计分母都需明确保留。

## 运行与恢复

默认解释器为已安装本地检索依赖的 `$HOME/miniconda3/envs/openrlhf/bin/python`；可用 `FIG3_PYTHON` 覆盖。图形环境另需 Matplotlib、pandas、NumPy、CairoSVG。

**通用 `all` 及第一个脚本默认清除整个实验输出。当前定点修复不要使用它们从头启动。** 对现有工作继续使用 `--resume` 或明确指定阶段。原始证据追加保存，处理结果直接覆盖，不创建版本、哈希或归档。

```bash
bash scripts/fig3_revision/fig3.sh status
bash scripts/fig3_revision/fig3.sh run --stage support --paper-id PAPER_ID --method gear
bash scripts/fig3_revision/02_evaluate.sh --resume
bash scripts/fig3_revision/03_recheck.sh --resume
```

报告修复使用 `runner.reset_scientific_report` 保留可复用的原生 Graph 事实和成功检索；普通 `--overwrite` 会清除该阶段相关检索，不能与该定点恢复混用。普通文件存在表示可续跑，改变科学输入后需明确清除受影响的下游任务。旧评价、问题对象和复核断点不能用于新报告。

真人问题每批最多 4 条，保留原问题、理由、引句和完整方法报告，不再生成中立问题摘要。对象漏答或返回越界 ID 时，仅补问缺失对象。已成功对象独立保存，避免重复计算。

统计先按论文计算，再进行宏平均；同时输出实际分母和微平均。置信区间采用固定种子 20260922 的 10,000 次论文级 bootstrap。各质量维度不汇总为一个创新分数。偏好使用 AB/BA 两个独立顺序；同模型判断和构造控制不等同于新人工验证。
