# Nature 创新分析稿件

这个目录是 LaTeX 主稿、独立 Limitation 稿、版本化图件和阅读 PDF 的本地入口。
在本地工作区选择需要的稿件版本，并使用该版本引用的图件目录。

以 v10 为例，主稿是 `manuscript_zh_v10.tex`，独立 Limitation 是
`limitation_zh_v10.tex`。主稿引用 `figures_v10/`。其中 `Fig03.pdf` 指向项目正式 Fig3，
其余图件按稿件中的版本路径读取。图件编号和依赖以对应的 LaTeX 文件为准。
稿件源文件、图件、PDF 和源码包由本地工作区提供。

项目图件的定位和导出命令见[图件入口](../../figures/README.md)。
