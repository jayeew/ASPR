# Nature 科学数据可视化

## 1. Skill 定位

把科学问题、数据结构和证据层级转换为清晰、透明、可复现的绘图方案。将“Nature 风格”理解为信息密度高、原始数据可见、效应量与不确定性明确、视觉编码一致且无障碍；不要将其理解为固定配色或装饰模板。

遵循以下优先级：

1. 保证数据与统计表达正确。
2. 让读者看见原始观测、样本量、分布或轨迹。
3. 优先呈现效应大小和不确定性，不只呈现 P 值与星号。
4. 用位置和长度承载精确比较，用颜色、面积和透明度承载次级信息。
5. 仅在图形结构有助于回答问题时使用“不常见”图形。

## 2. 触发条件与边界

在以下请求中使用本 Skill：

- 为实验结果、模型结果、组学数据、时序数据、网络或流向数据选择图形。
- 将均值柱状图、拥挤散点图、Venn 图或普通热图替换为信息更完整的形式。
- 设计单图、多面板主图、扩展数据图或图形摘要中的定量面板。
- 制定颜色、字体、尺寸、导出格式、图例和统计标注规范。
- 审核现有图形是否达到高水平期刊的清晰度、透明度和可访问性要求。
- 根据 R、Python、MATLAB、Prism 等环境给出可实现的绘图规格或代码。

不要：

- 在没有数据或统计结果时虚构数值、显著性、置信区间或样本量。
- 用“好看”覆盖数据缺陷、伪重复、选择性展示或不合适的统计比较。
- 保证某种图形能够提高录用概率。
- 把 Nature 主刊的版式值无条件套用到所有 Nature Portfolio 期刊；先检查目标期刊最新指南。

## 3. 目标

每次执行至少完成以下任务：

- 识别核心科学问题、比较单位、数据粒度、变量类型和依赖结构。
- 选出 1 个首选图形；必要时提供 1 个有明确取舍的备选图形。
- 明确横轴、纵轴、颜色、大小、形状、分面和排序分别编码什么。
- 说明原始数据、统计摘要、效应量、不确定性和样本量如何显示。
- 给出可直接使用的色值、版式和导出规格。
- 指出数据缺口、误读风险与慎用条件。
- 用户要求代码时，生成与数据结构匹配、可复现且可编辑导出的实现。

## 4. 输入要求

优先收集下列信息。缺失时做最少假设并显式标注；不要因非关键字段缺失而停止。

| 输入 | 必要内容 | 缺失时处理 |
|---|---|---|
| 科学问题 | 要比较、解释、验证或展示的结论 | 先用一句话重述推定问题 |
| 观测单位 | 每行代表患者、动物、细胞、批次、时间点或模型运行 | 标记为关键缺口，不推断独立样本数 |
| 变量结构 | 连续、离散、组成、时间、事件、网络、集合或矩阵 | 从字段与示例值推断并注明 |
| 分组与顺序 | 组别、时间、剂量、基线、目标亚组 | 使用科学顺序，不默认字母序 |
| 依赖关系 | 独立、配对、重复测量、嵌套、层级或空间相关 | 未知时避免独立样本统计结论 |
| 样本规模 | 每组 n、总 N、批次数与缺失比例 | 仅给方案，不生成统计量 |
| 统计目标 | 差值、比值、相关、预测误差、风险比或后验分布 | 推荐与问题一致的效应量 |
| 输出约束 | 目标期刊、单/双栏、软件、文件格式、静态/交互 | 默认白底静态双栏方案并说明 |
| 叙事重点 | 主要结论、对照与需要突出对象 | 无重点时使用中性色，不擅自强调 |

在可访问原始数据时，先检查：字段类型、单位、取值范围、缺失、重复、离群、组别不平衡、批次、配对键、层级键与零值含义。

## 5. 工作流程

按顺序执行，不跳过数据结构与统计完整性检查。

### 步骤 1：定义问题

用一句话写出“比较对象 + 指标 + 条件/时间 + 期望读出的量”。区分描述分布、估计效应、判断一致性、寻找关系、展示流向和呈现高维结构。

### 步骤 2：审计数据

确认独立观测单位、变量类型、样本量、配对/重复/嵌套关系和缺失。区分生物学重复与技术重复，避免把细胞数或重复测量数错误当作独立 n。

### 步骤 3：选择主图

使用下方决策树，选出能够直接回答核心问题的最简单图形。只有在复杂图形增加有效信息时才采用它。给出选择理由和一个不适用条件。

### 步骤 4：确定视觉编码

优先使用共同尺度上的位置；再使用长度、方向、形状、颜色和大小。不要让颜色和点大小重复表达同一变量。对跨面板重复出现的组别保持颜色、形状、顺序和方向一致。

### 步骤 5：加入统计层

按问题显示中位数/均值、效应量、置信区间或可信区间。明确误差条定义、精确 n、统计单位和参考线。配对数据保留连接关系；层级数据保留批次或个体结构。

### 步骤 6：应用配色与强调

先建立灰度层级，再给 1–3 个关键对象分配强调色。检查色觉缺陷、灰度打印、小尺寸和投影环境。不要用颜色代替标签。

### 步骤 7：组织版式

按“设计/总体结构 → 原始数据 → 效应量 → 关系或机制 → 稳健性”安排面板。统一轴、单位、字体、图例、留白和分面标签。

### 步骤 8：导出与质检

按最终印刷尺寸检查，不在放大视图中判断可读性。优先导出可编辑矢量文件；对位图检查实际像素、分辨率和图像完整性。执行本文件末尾的质量检查清单。

## 6. 图形选择决策树

```text
先问：读者需要从图中做哪一种判断？
├─ 比较组间连续数值
│  ├─ 需要看原始分布 → Raincloud 或 Sina
│  ├─ 需要看效应大小 → Gardner–Altman；多组相对基线用 Cumming
│  ├─ 需要看后验/Bootstrap 不确定性 → Half-eye
│  ├─ 组数多且关注分布位移 → Ridgeline
│  └─ 亚组/终点/系数很多 → Forest/Coefficient
├─ 比较同一对象的前后或重复测量
│  ├─ 两个条件/时间点 → Paired dot / Slopegraph
│  ├─ 多时间点且关注个体轨迹 → 透明轨迹 + 汇总区间
│  ├─ 关注排名变化 → Bump
│  └─ 关注离散事件时刻 → Event raster + rate curve
├─ 比较两个测量方法或算法
│  └─ 关注一致性而非相关性 → Bland–Altman
├─ 分析两个连续变量
│  ├─ 点不拥挤 → 散点 + 合适的模型/区间
│  ├─ 数千点以上或严重遮挡 → Hexbin
│  ├─ 比较群体二维覆盖 → Density contour
│  └─ 关注动态系统方向 → Phase portrait
├─ 展示很多时间序列
│  ├─ 需要精读少数序列 → 小倍图
│  └─ 需要扫描大量异常与模式 → Horizon graph
├─ 三个组成变量且总和固定为 1 或 100%
│  └─ Ternary plot
├─ 展示高维样本或矩阵
│  ├─ 两个指标编码到单元格 → Bubble heatmap / Dot matrix
│  ├─ 表达、注释和聚类需对齐 → Complex heatmap
│  ├─ 多种类别事件 × 样本 → Oncoprint
│  └─ 少量样本/代表方案跨多个连续指标 → Parallel coordinates
├─ 展示集合、流向或网络
│  ├─ 多集合精确交集 → UpSet
│  ├─ 对象跨阶段类别迁移 → Alluvial
│  ├─ 数量守恒的资源/能量/样本流 → Sankey
│  ├─ 少量节点的两两关系总览 → Chord
│  └─ 需要确定性网络布局与条件对比 → Arc diagram / Hive plot
└─ 以上都不匹配
   └─ 回到科学问题；优先选择点图、小倍图、矩阵或表格，不强行使用新奇图形
```

经验阈值只用于初筛：每组小样本优先显示全部点；点开始明显重叠时使用透明度、Sina 或密度；二维观测达到数千级且遮挡严重时优先 Hexbin/等高线。根据实际图幅和分布调整，不把阈值当作统计规则。

## 7. 不常见图形与适用数据

### 7.1 分布、效应量与一致性

| 图形 | 最适合的数据与问题 | 必须包含 | 不适用或风险 |
|---|---|---|---|
| Raincloud | 2–10 组连续变量；同时看分布、原始点和摘要 | 半小提琴、点、中心与区间；避免重复遮挡 | 极小 n 时密度不稳定；极大 n 时点过密 |
| Sina | 多组连续变量；偏态、双峰或离群；每个样本需可见 | 横向宽度按局部密度，点透明且不跨组 | 点很多时仍会拥挤；不要误读宽度为样本值 |
| Ridgeline | 8–30 个有自然顺序的组；观察分布随时间/剂量移动 | 共同 x 轴、清晰顺序、适度重叠 | 不适合精确比较均值或样本量很小的组 |
| Half-eye | 后验、Bootstrap 或模型参数分布 | 密度、中心、50/80/95% 区间或明确区间定义 | 没有重采样/后验样本时不要伪造密度 |
| Gardner–Altman | 两组独立或配对比较；强调差值及其精度 | 左侧原始数据，右侧效应量分布与 CI | 多组比较会拥挤；改用 Cumming |
| Cumming | 多个处理/剂量相对同一基线 | 原始数据、统一基线、每个对比的效应量与 CI | 比较网络复杂时需另用森林图或模型 |
| Forest/Coefficient | 多亚组、多终点、回归系数、风险比或敏感性分析 | 点估计、CI、零/一参考线、尺度说明 | 不用柱长替代区间；比值指标注意对数轴 |
| Bland–Altman | 新方法与金标准、两个测量平台的一致性 | 均值对差值、平均偏差、一致性界限；必要时比例偏差 | 不能只凭相关系数替代；重复测量需相应模型 |

### 7.2 时间、轨迹与事件

| 图形 | 最适合的数据与问题 | 必须包含 | 不适用或风险 |
|---|---|---|---|
| Paired dot / Slopegraph | 同一样本两个条件或时间点 | 可靠配对键、连接线、总体效应与区间 | n 很大时抽样不可随意；可用透明线与分布摘要 |
| Bump | 对象排名随时间、阶段或数据集变化 | 排名方向、直接标签、只突出少数轨迹 | 不展示绝对差距；并列排名需说明 |
| Horizon graph | 数十条长时间序列的异常扫描 | 基线、折叠层级图例、对称色阶 | 不适合精确读值或不熟悉该图的受众 |
| Event raster + rate | 神经放电、故障、症状、行为或调用事件 | 每行对象、事件刻度、对齐零点、平滑率及带宽 | 平滑率会掩盖个体差异；保留栅格 |

### 7.3 二维关系、组成与高维轨迹

| 图形 | 最适合的数据与问题 | 必须包含 | 不适用或风险 |
|---|---|---|---|
| Hexbin | 大规模二维连续观测、预测值对真实值、残差 | 计数/密度色标；必要时等值线、边缘分布和参考线 | 不用于稀疏数据；bin 大小会改变观感 |
| Density contour | 两组或多组二维联合分布、嵌入空间覆盖 | 统一带宽、4–7 层或标明 50/80/95% 区域 | 不把轮廓当作簇边界；低 n 时不稳定 |
| Ternary | 三个非负组成且和固定 | 三轴含义、总和约束、样本点或区域 | 三变量不封闭时禁用；难以精确比较微小差异 |
| Phase portrait | 动态系统、状态切换、收敛、振荡或滞后 | 时间方向箭头、起止点、统一采样解释 | 轨迹交叉多时需分面；不能省略时间方向 |
| Parallel coordinates | 少量代表方案的多指标画像、多目标优化 | 归一化规则、合理轴序、灰色背景线与重点线 | 大量彩色线会变成“意大利面”；轴方向须统一 |

### 7.4 集合、流向与网络

| 图形 | 最适合的数据与问题 | 必须包含 | 不适用或风险 |
|---|---|---|---|
| UpSet | 4 个以上集合的交集大小 | 集合点阵、连接线、交集计数、明确排序 | 交集极多时只显示有意义的前若干并说明截断 |
| Alluvial | 患者、样本、类别或聚类跨阶段迁移 | 每阶段节点、流带宽度、来源颜色一致 | 流交叉过多时聚合小类别或改用转移矩阵 |
| Sankey | 能量、物质、计算、样本筛选等数量守恒流 | 输入输出单位、守恒核对、损耗节点 | 普通流程图不要使用；节点间量不守恒时说明 |
| Chord | 约 8–15 个节点的两两关系矩阵 | 节点顺序、边权、少量重点关系 | 难做精确比较；必须配矩阵/条形图支撑主结论 |
| Arc diagram / Hive plot | 有自然顺序或社区轴的网络、跨条件结构比较 | 固定布局规则、节点/边定义、关键边强调 | 无明确排序或轴规则时不如矩阵稳定 |

### 7.5 组学与复杂矩阵

| 图形 | 最适合的数据与问题 | 必须包含 | 不适用或风险 |
|---|---|---|---|
| Bubble heatmap / Dot matrix | 基因×细胞、模型×数据集、药物×靶点 | 颜色与大小分别表达两个不同变量，提供双图例 | 点面积难精读；不要双重编码同一数值 |
| Oncoprint | 样本中的突变、扩增、缺失及共现 | 事件符号、样本排序、临床注释、事件频率 | 事件类型太多时先归并；不要只靠相近颜色区分 |
| Complex heatmap | 表达矩阵、多组学、临床注释与聚类联合展示 | 主矩阵与注释严格对齐、色标、距离和聚类方法 | 注释过多会掩盖主模式；避免任意聚类与彩虹色 |

## 8. 配色规范

### 8.1 通用规则

- 让颜色表达科学含义，不表达装饰层级。
- 先用浅灰承载背景信息，再用 1–3 个强调色突出结论。
- 对跨图重复对象使用同一颜色；不要在不同面板改变条件颜色。
- 避免红–绿对比和彩虹色标。需要无障碍时同时使用形状、线型、描边或直接标签。
- 离散类别通常控制在 6 个以内；类别更多时分面、聚合或仅突出重点。
- 连续变量使用感知均匀的顺序色；有意义的中心值才使用发散色。
- 发散色标围绕 0、基线或理论中点对称；没有中心含义时不要强行使用蓝–白–红。
- 保持文本为黑或白并满足高对比；不要用彩色小字充当图例。
- 透明度用于降低遮挡，不用于隐藏离群点或低频流。

## 9. 版式与导出规范

先读取目标期刊最新版说明。未提供目标期刊且用户明确要求 Nature 主刊风格时，采用以下默认值：

- 主图最终宽度：单栏 89 mm，双栏 183 mm；最大高度 170 mm。
- 正文图中文字：最终尺寸 5–7 pt；使用 Arial 或 Helvetica。
- 多面板标签：8 pt、粗体、正体、小写 `a, b, c...`。
- 面板按阅读顺序排列并紧凑利用空间；不要让所有面板机械等大。
- 使用 RGB。主图优先导出可编辑矢量 PDF/EPS；保留文字、线、箭头和比例尺的可编辑性，嵌入字体且不要转曲。
- 初稿位图至少 300 dpi；最终主图中的图像按 Nature figure guide 使用至少 450 dpi。不要把 DPI 要求套用到纯矢量元素。
- 在最终宽度下检查线条、点、标签、图例和显著性标注，不依赖放大阅读。
- 写全变量名、单位、样本量和误差定义。比较面板使用相同轴范围；任何截断或变换必须明确标注。
- 尽量直接标注线和关键对象；图例放在最近的空白区域，避免读者来回匹配。
- 只保留帮助读数的网格线；去除阴影、渐变背景、外框和无信息装饰。
- 图注应使图在脱离正文时仍可理解，并说明 n、重复类型、统计检验、区间和符号含义。

## 10. 多面板组合策略

根据证据链选择最少的必要面板；每个面板只承担一个主要判断。

### 10.1 组间实验

1. `a`：实验设计、样本流程或关键机制。
2. `b`：Raincloud/Sina 显示原始分布。
3. `c`：Gardner–Altman/Cumming 显示效应量与区间。
4. `d`：Hexbin/散点显示关键变量关系。
5. `e`：Forest 显示亚组、终点或敏感性分析。
6. `f`：独立验证、空间证据或机制验证。

### 10.2 高维与组学研究

1. `a`：PCA/UMAP/空间图提供总体结构，但不单独承担差异结论。
2. `b`：Dot matrix 显示标志物或模型×任务模式。
3. `c`：Complex heatmap 对齐表达、聚类与注释。
4. `d`：UpSet 显示多集合交集。
5. `e`：Alluvial 显示状态或标签迁移。
6. `f`：用可精确比较的点图/森林图验证关键发现。

### 10.3 时间与重复测量

1. `a`：干预与采样时间轴。
2. `b`：配对点图或个体轨迹。
3. `c`：相对基线的效应量与区间。
4. `d`：Ridgeline/Horizon 展示分布或大量序列变化。
5. `e`：Event raster 展示时间对齐事件。

### 10.4 方法一致性与模型验证

1. `a`：预测值对真实值的散点/Hexbin 与等值线。
2. `b`：Bland–Altman 显示偏差和一致性界限。
3. `c`：残差、校准或误差分布。
4. `d`：Forest 显示数据集、设备或亚组中的性能与区间。

跨面板保持组别顺序、颜色、符号、坐标方向和单位一致。若两个面板回答同一问题，只保留信息更完整者。

## 11. 禁用与慎用

### 11.1 默认禁用

- 3D 柱状图、3D 饼图、圆柱/圆锥柱和透视效果。
- 彩虹色标、仅靠红–绿区分、低对比彩色文字。
- 只显示均值的柱状图并隐藏原始点、分布和不确定性。
- 只用星号表达结果，不报告效应量、区间、精确 P 值或 n。
- 为制造差异而截断柱状图的零基线；若点图轴截断有科学理由，必须清楚标注。
- 未说明的双 y 轴、面积/体积装饰、平滑曲线掩盖原始数据。
- 用相关图证明一致性、用 UMAP 距离证明定量差异、用聚类树证明统计显著。

### 11.2 仅在满足条件时使用

| 图形 | 允许条件 | 必须配套 |
|---|---|---|
| Pie/Donut | 类别不超过 3–4 个且只需粗略整体占比 | 精确百分比标签；否则改用点图/条形图 |
| Radar | 少量对象的定性轮廓，所有轴同方向且尺度可比 | 数据表或点图 |
| Chord | 节点少、结构总览是目的 | 矩阵或排序条形图 |
| Sankey/Alluvial | 流量或迁移本身是结论 | 数值、单位与守恒/流失说明 |
| Streamgraph | 只强调组成随时间的整体形态 | 小倍图或精确趋势图 |
| Sunburst/Circle packing | 只展示层级总览 | 可排序表格或条形图 |
| Force-directed network | 探索性网络总览 | 固定布局、邻接矩阵或网络统计 |
| 3D surface | 两个自变量形成连续表面且交互/多个视角有必要 | 等高线或二维切片 |
| Parallel coordinates | 仅突出少量典型或 Pareto 方案 | 归一化说明和原始值表 |

## 13. 质量检查清单

任何硬性项失败时，不要称图形“可投稿”或“publication-ready”。

### 数据与统计

- [ ] 明确每行/每点代表什么，区分生物学重复、技术重复和重复测量。
- [ ] 保留配对、嵌套、批次与时间依赖，没有伪重复。
- [ ] 显示或报告每组精确 n、缺失和排除规则。
- [ ] 误差条、置信区间或可信区间定义清楚。
- [ ] 主结论由效应量和不确定性支持，不只由 P 值支持。
- [ ] 对数、标准化、截断、平滑、聚合和多重比较均已说明。
- [ ] 没有选择性隐藏离群点、失败实验或非显著结果。

### 图形选择与编码

- [ ] 图形直接回答核心科学问题，复杂度低于或等于信息需求。
- [ ] 原始数据在合理范围内可见；大样本遮挡已用密度、bin 或透明度处理。
- [ ] 位置/长度承担主要比较，面积、颜色和透明度没有被过度使用。
- [ ] 颜色和大小表达不同变量，图例与轴单位完整。
- [ ] 比较面板尺度一致；参考线、排序和方向有科学依据。
- [ ] 复杂总览图旁有可精确比较的点图、区间图、矩阵或表格。

### 颜色与可访问性

- [ ] 没有彩虹色标和仅靠红–绿的编码。
- [ ] 关键类别同时可由标签、形状、线型或位置识别。
- [ ] 连续/发散色标与数据语义匹配，中心值与范围合理。
- [ ] 颜色在所有面板中保持一致，并通过灰度和色觉缺陷模拟检查。
- [ ] 文字与背景对比充足，黄色未用于白底细线或小字。

### 版式与交付

- [ ] 已在最终栏宽和 100% 缩放下检查字体、点、线、图例与标注。
- [ ] 面板按小写字母顺序排列，留白紧凑但不拥挤。
- [ ] 字体、单位、数值精度、轴样式和图例风格一致。
- [ ] 矢量元素可编辑、字体已嵌入、颜色空间与目标期刊一致。
- [ ] 位图达到目标期刊要求且无不当裁剪、增强或压缩伪影。
- [ ] 图注能够独立解释对象、n、误差、统计、符号和缩写。
- [ ] 数据、绘图代码、软件版本、随机种子和导出参数可追溯。
