# 独立创新维度与指标遴选包

这个目录与现有 ASPR 程序完全分离，不导入、不修改现有实验代码。它只完成四件事：

1. 固定文献检索范围和检索式；
2. 建立文献证据表；
3. 建立按“数学测量家族”组织的指标库；
4. 按固定门槛自动产生最终维度和指标。

## 当前结论

文献层面支持两个直接的新颖性构念：

- **知识元素新颖性**：论文是否引入新的、年轻的、稀有的或语义遥远的知识元素；
- **知识重组新颖性**：论文是否以首次、罕见、异常或遥远的方式组合既有知识元素。

“问题、方法、理论、结果”被记录为创新贡献发生的位置，而不是与上述两个构念平行的计算机制。“首次出现、稀有度、异常度和语义距离”被记录为测量规则，也不再冒充机制。“知识多样性/跨学科性”属于邻近构念，不直接等于创新。

结合当前 ASPR 已冻结、已审计的数据边界，程序最终得到：

- **1 个可操作维度**：知识重组新颖性；
- **2 个最终指标**：
  - `M017_REFERENCE_OVERLAP_NOVELTY`：参考文献集合重叠新颖性，主指标；
  - `M015_FIRST_TIME_PAIR_INCIDENCE`：首次知识源组合占比，支持指标。

详细结果见 [遴选报告](outputs/selection_report.md)、[最终维度](outputs/final_dimensions.csv) 和 [最终指标](outputs/final_indicators.csv)。

## 为什么是这个结果

候选数量没有被预先规定。证据表目前包含 41 项来源；指标库从这些来源中抽取出 41 个数学测量家族，并另行登记 92 个参数或实现变体。程序执行以下硬门槛：

- 必须测量新颖性本身，而不是影响力、颠覆性或跨学科性；
- 必须有同行评议的公式或论文级应用来源；
- 公式、方向、时间边界和缺失规则必须可重复；
- 必须能在论文发表时计算，不能使用未来信息；
- 所需数据必须已在当前项目中冻结并经过审计；
- 总体覆盖率不低于 70%，每个大类不低于 50%；
- 重采样 Spearman 不低于 0.90，中位相对误差不高于 0.10；
- 时间测试和手算测试必须通过；
- 同一数学家族只保留一个预先排序的代表。

筛选规则中没有“必须留下几个维度”“每个维度至少一个指标”或“最终必须几个指标”等配额。

## 文件说明

- `protocol.json`：研究范围、数据边界、维度判定规则和禁止事项；
- `search_queries.json`：固定检索式；
- `search_snapshot.csv`：截至 2026-07-28 的 Crossref/OpenAlex 排序结果快照，共 454 条；
- `literature_evidence.json`：逐篇核验后的来源、角色、构念映射和不利证据；
- `dimensions.json`：构念定义及相邻构念边界；
- `metric_registry.json`：完整的范围内指标家族库、公式、来源、数据要求和审计值；
- `screening_rules.json`：机器执行的全部门槛与家族去重规则；
- `select_indicators.py`：独立筛选程序；
- `search_literature.py`：重新执行公开检索的程序；
- `tests.py`：无外部依赖的确定性和边界测试；
- `outputs/metric_screening_decisions.csv`：每个候选的所有通过/失败原因；
- `outputs/audit_manifest.json`：输入、程序和输出的 SHA-256。

## 运行

```bash
python3 innovation_indicator_selection/select_indicators.py
python3 innovation_indicator_selection/tests.py
```

如需重新获取公开检索结果：

```bash
python3 innovation_indicator_selection/search_literature.py --limit 25
```

公开数据库排序会随数据库更新而变化，因此论文复现应使用已经冻结并哈希的 `search_snapshot.csv`；重新检索用于更新版本，而不是覆盖本次证据快照。

## 重要解释边界

这是一份可复现的范围证据普查，不虚称为已经完成双人独立筛选的 PRISMA 系统综述，也不是回溯性预注册。41 项来源及其构念编码均有明确记录，但正式投稿前仍建议让第二位研究者在不知道最终结果的情况下复核来源纳入和构念编码。

最终两个指标只说明当前参考文献数据能够支持“知识重组新颖性”的两个观察面，不代表论文的完整创新性、正确性、质量或未来影响力。首次组合指标的独立验证证据存在分歧，因此被明确标为支持指标；参考重叠指标的证据等级为中等，而不是“创新真值”。
